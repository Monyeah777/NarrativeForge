# 模块 情感:M22 · 三冲动驱动

> 类别：情感｜来源：校园｜挂载点：P40 行为决策（active）｜依赖：M00、M40｜发布：`npc_action`

## 1. 职责

将 NPC 的大五人格（Big Five）映射为**三冲动**（escape 逃避 / sexual 靠近 / mischief 挑衅），驱动 NPC 的自主行为决策。核心约束：**三冲动仅驱动 NPC，主角豁免**——主角行为由玩家/剧情决定，不由本模块越权代劳。

## 2. 出厂规则（大五 → 三冲动）

```yaml
base_impulse_rules:
  escape:   神经质 > 50   → escape 高（遇威胁先跑/回避）
  sexual:   外向 > 50     → sexual 高（主动靠近/亲近）
  mischief: 宜人 < 50 且 开放 > 50 → mischief 高（爱挑衅/恶作剧）
  下调:     尽责 > 50     → 三项冲动整体乘系数下调（自控力强）
  上限:     单项冲动强度 0-100，多来源取叠加后 clamp(0,100)
```

## 3. 扳机检测（6 步）

```yaml
trigger_detect(event_text, npc):
  1. 取 npc.fears[].trigger_words
  2. event_text 与 trigger_words 做词级匹配（含同义/近义扩展）
  3. 命中恐惧 → 对应冲动 +（恐惧越强加成越大）
  4. 认知负荷修正：高负荷 → 冲动波动加大（易走极端）
  5. 情绪修正：当前情绪（Plutchik 轮）同向放大、反向抑制
  6. 输出: {impulse: 候选, strength: 0-100}
```

## 4. 决策规则（4 条）

```yaml
decision_rules:
  - 冲动强度 > 60 → 该冲动权重 0.7，直接主导行为
  - 两冲动差值 < 5 → 僵住/犹豫，行为权重 ×0.5（表现踌躇）
  - 恐惧命中且 escape 主导 → 行为 = 回避/逃离/拒绝正面回应
  - 无命中 → 按日常行为基线（M13 日程）行动，不触发冲动
输出: npc_action {npc_id, impulse, strength, behavior, target}
```

## 5. 事件契约

```yaml
publish: npc_action
  payload: {npc_id, impulse, strength, behavior, target, tick}
  subscribers: [M40, M43, M55]
```

## 6. 违例与边界

- 主角不进入三冲动计算（豁免）；若剧情需主角冲动，走事件:M22 显式编剧。
- NPC 冲动行为必须先过 M23 认知边界，再交 M40 结算关系变化。
- 冲动永不直接输出为内心独白，只表现为行为信号（配合写作 DNA1）。

## 7. 机制约束（v0.7.12 冲动-社会关系隔离）

> 补丁来源：v0.7.12_patch（冲动-社会关系隔离）；落点：本模块 §6、校园包 README §4、06 §9 红线 7。

- **冲动驱动边界**：三冲动只驱动物理位移 / 动作连带 / 视线停留等**表层行为信号**；告白、交往、约会、关系推进等驱动权从冲动层整体切除。
- **关系推进权归属**：冲动触发的靠近意图只产生"接近信号"（靠近站位、递水、偷看、回避脚步），是否升级为关系行为由 M40（关系深度）与 M41（恋爱进阶）按 INTERACTION_DEPTH 判定——冲动永不直接产出 `relationship_change`（I3 事件归属）。
- 违例形态：sexual 冲动直接写"他向她告白了" → 协议事故；合规形态：sexual 冲动只写"他挪近了一个座位"，关系是否推进交 M40 结算。
- 主角豁免不变（§6 首条）：主角行为由玩家/剧情决定，不进三冲动计算。
