# 模块 M43 · 情敌系统

> 类别：情感｜来源：校园｜挂载点：P40 行为决策（active）｜依赖：M40、M41｜发布：`confession_event`

## 1. 职责

为恋爱线注入**竞争张力**：生成情敌 NPC、推进情敌行为、触发告白竞争事件，让暧昧/恋爱阶段出现波动与选择压力。

## 2. 情敌生成

```yaml
rival_spawn:
  触发: 主角与目标 NPC 进入好感阶段（depth ≥ 40）后小概率激活
  配置: 从资产库 ATTR_TEMPLATES 取样生成情敌（大五人格/恐惧/背景）
  定位: 情敌对目标 NPC 持高初始好感；对主角态度由性格决定（可敌可友可中立）
  数量: 同目标 NPC 情敌 ≤ 2（防止拥挤）；可被事件:M22 编剧扩展
```

## 3. 情敌行为驱动

```yaml
rival_behavior:
  节拍: 订阅 npc_action（情感:M22）与 tick_day
  常规: 按 M13 日程接近目标 NPC → 提高目标对情敌的认知
  竞争: 主角与目标 depth 停滞/下降时，情敌主动示好（触发 confession_event 概率上升）
  破坏: 性格含高 mischief 的情敌可触发阻挠事件（给主角制造误会）
```

## 4. 告白竞争事件

```yaml
confession_event:
  触发窗口: 目标 NPC 进入暧昧阶段且情敌在场/近期活跃
  结果分支:
    - 情敌抢先告白成功 → 目标进入恋爱（与情敌）→ romance_state_change 通知 M41/M55
    - 主角介入成功 → 目标拒绝情敌 → 情敌转负面（可触发遗憾/复仇线）
    - 犹豫未决 → 维持暧昧，情敌好感上涨（时间压力）
```

## 5. 事件契约

```yaml
subscribe: [relationship_change, romance_state_change, npc_action]
publish: confession_event
  payload: {rival_id, target_npc, outcome, tick}
  subscribers: [M41, M55]
```

## 6. 违例与边界

- 情敌系统仅在校园情感类内容启用（P02）；西幻管线不加载。
- 情敌失败线不得无限纠缠——连续失败 2 次后该情敌降级为普通 NPC（尊重 M65 遗憾节奏）。
