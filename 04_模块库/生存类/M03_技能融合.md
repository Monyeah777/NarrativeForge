# 模块 M03 · 技能融合

> 类别：生存｜来源：西幻｜挂载点：P40 行为决策（available）｜依赖：M01、M02、M20｜发布：无

## 1. 职责

管理**技能习得、融合、分解与继承**，以及多轴技能（SOV）流派构筑（对应骨架 M03）。

## 2. 技能习得机制

```yaml
skill_learn:
  来源: 职业成长表解锁 / NPC 教学（M13）/ 技能书（M05 物品）/ 事件奖励（M18）
  习得条件: 前置技能 + 等级门槛 + 材料（如适用）
  技能等级: 1-10，熟练度随使用增长（M04 战斗/ M17 生产使用计数）
```

## 3. 技能融合系统（9 配方）

```yaml
skill_fusion:
  规则: 两技能满足配方 → 合出新技能（名称+效果合并+成长线合并）
  配方数: 9 条（具体配方见资产库西幻包 skill_fusion_recipes）
  示例: [火焰箭] + [爆裂] → [爆炎矢]（伤害+范围）
  失败保护: 融合失败不损失原技能（可重试）
```

## 4. 技能分解与继承

```yaml
分解: 高等级技能可拆回低阶组件（回收成长资源，损耗 20%）
继承: 死亡/转生时（生存:M10）按继承规则保留部分技能：
  - 血脉技能（种族/天赋）100% 继承
  - 职业技能按遗物/祝福保留（详见 生存:M10 与资产库）
```

## 5. 多轴技能 SOV 与流派构筑

```yaml
SOV: 技能按 风格Style / 对象Object / 载体Vehicle 三轴标注
  构筑: 玩家按 SOV 组合构筑流派（如"火焰剑术流派"= 火元素+剑+近战）
  流派加成: 同轴技能组合达到阈值 → 流派等级提升（全局修正）
```

## 6. 组合技系统（7 个，需伙伴配合）

```yaml
combo_skills:
  条件: 两名及以上伙伴各自持有关键技能且在场
  数量: 7 个组合技（如"双人奥术屏障""连携背刺"）
  触发: M13 伙伴在场 + 战斗轮 M04 提供触发窗口
```

## 7. 事件契约

```yaml
subscribe: [combat_result, spell_cast, level_up]   # 熟练度/习得检查
```

## 8. 违例与边界

- 技能融合结果须先在 M24 组合注册表登记，未登记组合一律不生效。
- 禁止跨系无配方硬融（保持规则可解释）。
