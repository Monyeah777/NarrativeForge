# 模块 M02 · 种族天赋

> 类别：生存｜来源：西幻｜挂载点：P20 角色状态（active）｜依赖：M00、M20｜发布：无

## 1. 职责

管理**八大种族**的身份、属性修正与天赋树，以及亚种/杂交规则（对应骨架 M02）。

## 2. 八大种族总览

```yaml
races:
  人类:     平衡成长；天赋: 万能适应（属性点自由分配+）
  精灵:     dex/int 偏向；天赋: 自然亲和（感知/森林判定+）
  矮人:     str/con 偏向；天赋: 锻造精通（生产+ 对毒抗性+）
  兽人:     str 高 con 高；天赋: 狂暴（战斗强度+ 理智波动-）
  龙裔:     元素抗性天赋；天赋: 龙血（可学龙语魔法）
  半身人:   dex/luc 偏向；天赋: 幸运（暴击/掉落+）
  亡灵:     生存消耗异化（不饿不渴）；天赋: 不死韧性（复活代价-）
  妖精:     wis/cha 偏向；天赋: 幻术亲和（魔法/社交修正+）
种族属性修正: 创建时一次性加成，等级成长不再次叠加
```

## 3. 天赋系统

```yaml
talent_tree:
  每族 1 主天赋 + 2-3 分支（随等级解锁）
  天赋效果作用于: 战斗（M04）/魔法（M11）/生产（M17）/社交（M13）判定
  天赋与职业叠加规则: 同类修正取叠加后 clamp（防数值爆炸）
```

## 4. 亚种与杂交规则

```yaml
hybrid_rules:
  亚种: 同族血统变异（如暗精灵、山矮人）→ 主天赋替换为亚种专属
  杂交: 跨族后代（M19 遗传）→ 主属性取父母均值，天赋取一方主线
  禁忌: 特定组合（如龙裔×亡灵）须 M20 世界知识库校验合理性
```

## 5. 种族专属生成规则

- NPC/玩家创建时种族决定：初始属性、外观意象词库、所属区域（M07）、默认阵营倾向（M14）。
- 种族刻板印象写入 M20，供 NPC 对话与事件合理取材（不越 M23 边界）。

## 6. 违例与边界

- 种族创建后不可变（除非事件:M22 编剧转生线并显式标记）。
- 杂交后代天赋判定唯一入口在本模块，M19 遗传只产出"双亲基因型"。
