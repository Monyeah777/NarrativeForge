# 模块 M16 · 建筑据点
> 类别：世界｜来源：西幻｜挂载点：P60 长期演变（active）｜依赖：M00、M19｜被依赖：M15、M09｜发布：无

## 1. 职责
管理**建筑模板、居民模板与城镇据点生成**：定义建筑类型与功能、生成城镇据点（settlement）及其居民，维护据点税收与事件。对应西幻骨架 M16（building_templates / resident_templates / random_resident_generation / 据点事件税收）。为 M15 帮派提供地盘载体、为 M09 经济提供商店/市场实体。

## 2. 建筑与据点规则
```yaml
building_template:
  id: # 建筑类型（住宅/商店/工坊/公会/神殿/城防…）
  function: 功能
  upgrade: 升级链与造价（联动 M09）
settlement:
  id: 城镇/村落实例
  buildings: []  # 建筑清单
  residents: []  # 居民清单（模板生成，见下）
  control: # 控制方（阵营 M14 / 帮派 M15）
  tax: 税率与周期（产出进 M09 经济）
resident:
  generation: 模板 + 随机生成（性格/职业/关系）
  继承: 据点管理者/继承人走 M19 遗传后代
event_tax:
  据点事件库: # 7 类事件（火灾/瘟疫/集市/袭击…）
  触发: _trigger_events → _check_event_conditions → _apply_event
```
- 建筑模板全表、居民模板、事件库数据 → 05_资产库/西幻包。

## 3. 事件契约
```yaml
subscribe: []  # 本模块为纯状态维护方，不订阅运行时事件
publish: []    # 不发布事件；据点状态经查询接口供 M09/M15 读取
```
- 据点状态（get_settlement_summary）由 M50 在第 12 步世界结算时轮询读取，作为 M09 定价与 M15 地盘判定的输入。

## 4. 结算流程
1. 收到世界结算信号（M50），检查据点事件条件。
2. 触发事件 → 应用建筑/居民/税收变更。
3. 税收按周期计入 M09 经济库存。
4. 据点控制方变更（帮派火并结果）由 M15 回写。

## 5. 违例与边界
- M16 维护**静态结构 + 据点状态**；NPC 个体行为走 M13、建筑内交易价格走 M09、遗传继承走 M19。
- 居民生成不得直接创造"主角级"角色（命运由事件:M22 塑造）。
- 建筑升级/税收数值须经 M09 校准，禁止脱离经济的凭空产出。
