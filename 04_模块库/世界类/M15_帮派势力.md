# 模块 M15 · 帮派势力
> 类别：世界｜来源：西幻｜挂载点：P60 长期演变（active）｜依赖：M14、M16｜被依赖：M18｜发布：`faction_event`

## 1. 职责
管理**帮派结构、势力范围与帮派事件**：维护 13 帮派的地盘、首领、目标与资源，执行帮派行动（扩张/火并/交易/秘密行动），驱动地盘争夺与玩家-帮派互动。对应西幻骨架 M15（gangs 帮派系统）。帮派是阵营（M14）的基层执行体，地盘归属联动 M16 建筑据点。

## 2. 帮派规则
```yaml
gang:
  id: # 13 帮派总表
  territory: []  # 地盘（据点列表，联动 M16）
  leader: # 首领 NPC，联动 M13
  hierarchy: # 内部结构（首领/干部/成员/外围）
  resources: # 资金/武器/情报
gang_action:
  type: 扩张 | 勒索 | 火并 | 交易 | 渗透 | 秘密行动
  cost: 资源消耗
  outcome: 成功/失败 → 地盘变化
territory_contest:
  争夺触发: 相邻地盘/资源冲突
  结算: 战斗走 M04，胜负改地盘归属
intel:
  秘密与情报: 玩家可购买/窃取（经 M23 认知边界裁剪）
```
- 13 帮派数据表、内部结构、行动类型 → 05_资产库/西幻包。

## 3. 事件契约
```yaml
subscribe:
  reputation_change: # M14 → 声望升降驱动帮派态度
publish:
  faction_event:
    payload: {gang, action_type, target_area, outcome, territory_delta[], rep_impact}
    subscribers: [M14, M18]
```

## 4. 结算流程
1. 帮派行动按资源/时机条件判定（受 M14 声望与 M16 据点状态影响）。
2. 火并类行动走 M04 战斗结算，胜负回写地盘。
3. 地盘变化同步 M16 据点控制方。
4. 发布 faction_event，M14 更新阵营声望、M18 判断是否触发混沌扰动。

## 5. 违例与边界
- M15 只管帮派层面行动与地盘；**个体战斗裁决归 M04**，**玩家个人声望归 M14**。
- 帮派秘密情报属于隐藏域内容，供给玩家前须经 M23 裁剪。
- 帮派事件引发的重大叙事（灭帮/政变）交事件:M22 组织。
