# 模块 M09 · 经济贸易
> 类别：世界｜来源：西幻｜挂载点：P60 长期演变（active）｜依赖：M07、M17｜被依赖：M17、事件:M22｜发布：`market_event`

## 1. 职责
管理**商品定价、市场波动、投资与商店刷新**：以 37 种商品为基础建立价格模型，按聚落类型/区域/季节计算实际价格，周期性发布市场事件制造波动。对应西幻骨架 M09（commodities / market_events / investments / shop_refresh_rules）。与 M17 生产制造构成"供给-价格双向校准环"。

## 2. 定价与市场规则
```yaml
price(commodity, 聚落, 区域, 季节):
  实际价格 = base_price × demand[聚落类型] × region_mult[区域] × season_mult[季节]
  # 示例：谷物 base 10 → 北境村庄冬季 = 10 × 1.2 × 1.5 × 1.3 = 23.4
market_event:
  type: 缺货 | 丰收 | 黑市 | 商路中断 | 投机
  duration: # 若干 tick_day 后恢复
  price_delta: # 波动幅度
investments:
  # 玩家投资项：本金、周期、回报率、失败风险
shop_refresh_rules:
  # 5 城镇各商店的补货/刷新周期与配额
```
- 37 商品表、11 区域系数、四季系数、5 城镇商店规则 → 05_资产库/西幻包。

## 3. 事件契约
```yaml
subscribe:
  tick_day: # 通用:M10 → 周期性价格结算
  weather_state: # M08 → 季节/天气触发涨跌
  travel_event: # M07 → 商路可达性影响市价
  production_output: # M17 → 产出供给回调，压低价格
publish:
  market_event:
    payload: {type, commodity, price_delta, duration, affected_towns[]}
    subscribers: [M17, 事件:M22]
```

## 4. 供给-价格双向校准环
- M17 产出 → `production_output` → M09 将供给注入库存，价格回落。
- M09 价格波动 → `market_event` → M17 依据利润率调整生产决策。
- 两模块互为订阅者/发布者，**结算顺序由 M50 统一编排**，禁止任一模块单独推进经济回合。

## 5. 违例与边界
- M09 **只定价与波动，不产出商品**（产出归 M17）、**不结算玩家金钱操作**之外的交易动作本身。
- 价格公式参数只允许来自资产库表，禁止硬编码新商品。
- 大型经济叙事（饥荒/商战剧情）交事件:M22 组织，M09 只提供数值背景。
