# 模块 M14 · 阵营声望
> 类别：世界｜来源：西幻｜挂载点：P60 长期演变（active）｜依赖：M13｜被依赖：M15、M06｜发布：`reputation_change`

## 1. 职责
管理**势力阵营、声望等级与阵营关系动态**：维护玩家与各阵营的声望数值与等级、阵营间关系类型（战争/和平/贸易/盟约）、以及声望驱动的势力阴谋解锁。对应西幻骨架 M14（factions 势力系统 / faction_relations / plots）。群体声望的**唯一真相来源**（个体好感归 M13）。

## 2. 声望与阵营规则
```yaml
faction:
  id: # 阵营总表（如 王国/教会/盗贼公会/法师塔…）
  territory: # 控制区域，联动 M07/M16
  relation_type: 战争 | 敌对 | 中立 | 友好 | 贸易 | 盟约
reputation_tier: # 声望等级体系
  由数值门槛划分（敌对/冷淡/中立/友善/尊敬/崇拜…）
reputation_gain:
  交互贡献: # 来自 M13 interaction_update
  任务贡献: # 来自 M06 quest_state
  帮派事件: # 来自 M15 faction_event（可反向影响）
plot:
  势力阴谋: 声望达阈值解锁（plots）
```
- 势力总表、声望门槛、阵营关系类型表 → 05_资产库/西幻包。

## 3. 事件契约
```yaml
subscribe:
  interaction_update: # M13 → NPC 交互对阵营声望的贡献
publish:
  reputation_change:
    payload: {faction_id, player, delta, old_tier, new_tier, reason}
    subscribers: [M15, M13, M06]
```

## 4. 结算流程
1. 收到 interaction_update / 任务完成等来源的声望输入。
2. 更新玩家×阵营声望数值并判定 tier 变化。
3. 若跨 tier，检查 plot 解锁条件。
4. 发布 reputation_change，M15 调帮派态度、M13 调 NPC 对话口径、M06 开放/关闭任务。

## 5. 违例与边界
- M14 维护**群体声望与阵营关系**，不生成 NPC 个体行为（M13）与任务文本（M06）。
- 帮派（M15）是阵营的子集形态：帮派声望变更须回写 M14，禁止双轨数值。
- 声望不可凭空加减，必须有来源事件（交互/任务/帮派），防刷分。
