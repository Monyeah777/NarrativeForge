# 管线 P01 · 标准管线
> 默认活跃管线。以“数据基座→世界推进→角色状态→事件生产→行为决策→交互执行→长期演变→叙事素材→输出呈现”九层线性推进，主循环回卷。
> 实例声明：本管线是通用骨架 **P00**（03_管线库/P00_通用文档生成管线.md）在**叙事领域**的标准装配——九层位名与模块挂载为叙事特化，层名可按领域替换。
```yaml
Pipeline:
  id: P01
  name: 标准管线
  structure:
    type: linear
    flow:
      - from: P00
        to: P10
      - from: P10
        to: P20
      - from: P20
        to: P30
      - from: P30
        to: P40
      - from: P40
        to: P50
      - from: P50
        to: P60
      - from: P60
        to: P70
      - from: P70
        to: P80
      - from: P80
        to: P00
        condition: 主循环回卷（M50 调度下一回合）
  layers:
    - id: P00
      name: 数据基座
      description: 初始化数据结构与存档装载；M00 数据结构在此建立角色/关系/世界/叙事四类数据槽
      optional: false
      default_modules: [M00]
      allowed_modules: [M00, M20]
    - id: P10
      name: 世界推进
      description: 时间推进与天气变化；tick_day 事件广播给订阅方
      optional: false
      default_modules: [通用:M10]
      allowed_modules: [通用:M10, M08]
    - id: P20
      name: 角色状态
      description: 角色属性、职业成长、遗传与认知边界结算；产出角色状态增量
      optional: false
      default_modules: [M01, M02, M19, M23]
      allowed_modules: [M01, M02, M03, M19, M23]
    - id: P30
      name: 事件生产
      description: 事件叙事、任务剧情、混沌事件、NPC 交互请求在此生成候选事件集
      optional: false
      default_modules: [事件:M22, M06, M18, M13]
      allowed_modules: [事件:M22, M06, M18, M13, M12]
    - id: P40
      name: 行为决策
      description: 三冲动驱动与关系/恋爱/情敌系统裁决 NPC 行为倾向；战斗与魔法亦可作为决策出口
      optional: false
      default_modules: [情感:M22, M40, M41, M43, M55]
      allowed_modules: [情感:M22, M40, M41, M43, M55, M04, M11, 生存:M10, M24]
    - id: P50
      name: 交互执行
      description: 战斗、魔法、对话、生产等行为的实际执行与结算
      optional: false
      default_modules: [M04, M11, M12, M17]
      allowed_modules: [M04, M11, M12, M17]
    - id: P60
      name: 长期演变
      description: 世界侧长期状态：地图、经济、阵营、帮派、建筑、幽灵遗憾沉淀
      optional: true
      default_modules: [M65, M07, M09, M14, M15, M16]
      allowed_modules: [M65, M07, M09, M14, M15, M16, M19]
    - id: P70
      name: 叙事素材
      description: 世界知识库与组合规则为输出层提供设定素材与组合校验
      optional: true
      default_modules: [M20, M24]
      allowed_modules: [M20, M24]
    - id: P80
      name: 输出呈现
      description: 输出生成器按写作 DNA 渲染叙事文本与状态面板
      optional: false
      default_modules: [M80]
      allowed_modules: [M80]
  dependencies:
    - from: P20
      to: P30
      reason: 角色状态是事件生产的输入画像
    - from: P30
      to: P40
      reason: 事件文本是冲动扳机与关系裁决的输入
    - from: P40
      to: P50
      reason: 决策结果驱动行为执行
    - from: P50
      to: P60
      reason: 行为结果写入世界长期状态
  tags: [人物驱动, 世界驱动, 情绪流]
```
## 运行规则
- 每回合由 M50 主循环按注册表 execution_order 依序调度各层默认模块。
- optional=true 的层（P60/P70）缺模块时跳过，不阻塞回合。
- 层内模块输出写入数据槽；层间仅通过数据槽与事件通信（I3）。
- 管线的可替换性：换用 P02/P03 时，注册表 mount_points 与 execution_order 同步切换。
