# 管线 P01 · 标准管线（官方核心装配）
> 官方默认活跃管线。以“数据基座→世界推进→角色状态→事件生产→行为决策→交互执行→长期演变→叙事素材→输出呈现”九层线性推进，主循环回卷。
> 实例声明：本管线是通用骨架 **P00**（03_管线库/P00_通用文档生成管线.md）在**叙事领域**的**官方核心标准装配**——仅挂载 04_模块库 保留的 13 件核心/共享模块；题材模块由社区包（校园情感领域包 / 西幻生存领域包）按 P02/P03 装配补充。
```yaml
Pipeline:
  id: P01
  name: 标准管线（官方核心装配）
  structure:
    type: linear
    flow:
      - from: P00
        to: P10
      - from: P10
        to: P20
      - from: P20
        to: P30
      - from: P30
        to: P40
      - from: P40
        to: P50
      - from: P50
        to: P60
      - from: P60
        to: P70
      - from: P70
        to: P80
      - from: P80
        to: P00
        condition: 主循环回卷（M50 调度下一回合）
  layers:
    - id: P00
      name: 数据基座
      description: 初始化数据结构与存档装载；M00 在此建立角色/关系/世界/叙事四类数据槽
      optional: false
      default_modules: [M00]
      allowed_modules: [M00, M20]
    - id: P10
      name: 世界推进
      description: 时间推进与季节天气；tick_day / weather_state 事件广播给订阅方
      optional: false
      default_modules: [通用:M10]
      allowed_modules: [通用:M10, M08]
    - id: P20
      name: 角色状态
      description: 认知边界视角裁剪：叙事只呈现主角当前可知信息（M23）
      optional: false
      default_modules: [M23]
      allowed_modules: [M23]
    - id: P30
      name: 事件生产
      description: 事件叙事、任务剧情、NPC 交互在此生成候选事件集与交互请求
      optional: false
      default_modules: [事件:M22, M06, M13]
      allowed_modules: [事件:M22, M06, M13, M12]
    - id: P40
      name: 行为决策
      description: 题材行为裁决层（冲动/关系/战斗/魔法等决策出口随社区题材包装配）；官方核心装配下为空层，事件候选直通 P50
      optional: true
      default_modules: []
      allowed_modules: []
    - id: P50
      name: 交互执行
      description: NPC 对话模板供给与交互行为执行（M12 台词库）
      optional: false
      default_modules: [M12]
      allowed_modules: [M12]
    - id: P60
      name: 长期演变
      description: 世界侧长期状态层（地图/经济/阵营/帮派/建筑/遗憾沉淀随社区题材包装配）；官方核心装配下为空层
      optional: true
      default_modules: []
      allowed_modules: []
    - id: P70
      name: 叙事素材
      description: 世界知识库与组合规则为输出层提供设定素材与组合校验
      optional: true
      default_modules: [M20, M24]
      allowed_modules: [M20, M24]
    - id: P80
      name: 输出呈现
      description: 输出生成器按写作 DNA 渲染叙事文本与状态面板
      optional: false
      default_modules: [M80]
      allowed_modules: [M80]
  dependencies:
    - from: P20
      to: P30
      reason: M23 认知边界裁剪是事件生产的前置视角过滤
    - from: P30
      to: P40
      reason: 事件候选集是行为决策输入（P40 为空层时直通 P50）
    - from: P40
      to: P50
      reason: 决策结果驱动交互执行（P40 为空层时直通 P50）
    - from: P50
      to: P60
      reason: 交互结果写入长期状态（P60 为空层时跳过）
  tags: [人物驱动, 世界驱动, 情绪流]
```
## 运行规则
- 每回合由 M50 主循环按注册表 execution_order 依序调度各层默认模块；空层（P40/P60 核心装配下）直接跳过，不阻塞回合。
- optional=true 的层（P40/P60/P70）缺模块时跳过；题材模块由社区包装配后写入对应层。
- 层内模块输出写入数据槽；层间仅通过数据槽与事件通信（I3）。
- 装配社区题材包（P02 校园情感 / P03 西幻生存）时，社区包负责把题材模块追加进对应层的 default/allowed，并按社区包索引同步注册表 mount_points 与 execution_order。
