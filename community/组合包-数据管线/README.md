# 组合包-数据管线（组合包 · 由组合引擎产物化）
> 定位：**自由组合包**——由 `nf combine materialize` 从 4 个域包组合而成；
> 组合包**不新增内容资产**，全部模块经 `references` **只读借阅**（源包模块不改号、资产不复制）。
> 唯一机读真相 = `protocol.yaml`；本 README 为人读速览（双源一致由 check14 ⑥ 断言）。
> 管线：**P108** 组合包-数据管线装配流（派生自 P00 九层骨架）｜借阅模块 **8** 个｜产出面 8 件（含 T4 证书）

## 1. 组合构成

| 源包 | 借阅模块 |
|---|---|
| 合成数据生成域包 | `合成数据生成:M01`、`合成数据生成:M02` |
| 数据采集与清洗域包 | `数据采集与清洗:M01`、`数据采集与清洗:M02` |
| 评测基准与排行榜域包 | `评测基准与排行榜:M01`、`评测基准与排行榜:M02` |
| 预训练与继续预训练域包 | `预训练与继续预训练:M01`、`预训练与继续预训练:M02` |

## 2. 层位堆叠（available 槽）

| 层 | 模块（堆叠序） |
|---|---|
| P40 | `合成数据生成:M01`、`数据采集与清洗:M01`、`评测基准与排行榜:M01`、`预训练与继续预训练:M01` |
| P60 | `合成数据生成:M02`、`数据采集与清洗:M02`、`评测基准与排行榜:M02`、`预训练与继续预训练:M02` |

## 3. 复现与验收

```
python scripts/nf.py combine plan --packs "数据采集与清洗域包,合成数据生成域包,预训练与继续预训练域包,评测基准与排行榜域包"
python scripts/nf.py combine verify
python scripts/nf.py output verify
```

## 4. 边界

- 组合包**不改源包**：借阅只读；组合不产生新内容资产。
- 合法性与可复算性由组合证书（`outputs/COMBO_CERT.json`）与五不变量保证；
  内容质量仍由各源包口径与 T4 面承担。
