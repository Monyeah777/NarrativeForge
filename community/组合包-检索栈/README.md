# 组合包-检索栈（组合包 · 由组合引擎产物化）
> 定位：**自由组合包**——由 `nf combine materialize` 从 3 个域包组合而成；
> 组合包**不新增内容资产**，全部模块经 `references` **只读借阅**（源包模块不改号、资产不复制）。
> 唯一机读真相 = `protocol.yaml`；本 README 为人读速览（双源一致由 check14 ⑥ 断言）。
> 管线：**P109** 组合包-检索栈装配流（派生自 P00 九层骨架）｜借阅模块 **6** 个｜产出面 8 件（含 T4 证书）

  内容质量仍由各源包口径与 T4 面承担。
