# 模块 M92 · 轻混装配执行

> 类别：轻混｜来源：校园西幻轻混组合包｜挂载点：P50 交互执行（active）｜编号段：M91-M99 社区预留
> 依赖：M00（数据结构）、M50（主循环）、M80（输出生成器）——官方核心（R1 core_only）
> 发布：`campus_anonymous_gift`｜订阅：`production_output`
> 引用装配：西幻 M17 生产制造（production_output 上游）/ 校园 M55 情书链（confession_event 由 M91 转译后经本模块收口）
> 对应 protocol.yaml modules[1].id=M92｜模板制作指令包 格式一（八要素）示例落盘

```yaml
machine_contract:
  schema: "1"
  id: M92
  name: 轻混装配执行
  category: 轻混
  layer: P50
  inputs: []
  outputs: []
  events:
    publish:
      - campus_anonymous_gift
    subscribe:
      - production_output
  interfaces: []
```

## 1 职责

轻混执行层（P50）装配模块：把西幻侧生产输出（M17 `production_output`）与校园侧馈赠意图（M91 `campus_gift_intent`）**跨语境再包装**为校园可落地的匿名礼物动作 `campus_anonymous_gift`。它是轻混装配的「最后一段管道」——订阅源包事件、装配为本包事件，不搬移 M17 本体（M17 仍驻西幻包 P50 default）。

## 2 输入输出（八要素）

- 编号：M92（社区预留段，protocol.yaml module_id_range 在册）
- 名称：轻混装配执行
- 类别：轻混（组合包独占类别，与源包 [情感]/[生存] 无交集——R2）
- 层：P50 交互执行（active，mount_layers.P50.default=[M92]）
- 输入（订阅）：production_output（西幻 M17）
- 输出（发布）：campus_anonymous_gift
- 可替换：是（组合包装配位；卸载后 P50 回落源包 M17 单语境产出，不影响源包独立运行）
- 核心逻辑：见 §3

## 3 核心逻辑：跨语境再包装

```yaml
# production_output 到达 → 意图匹配 → 物品语境映射 → 匿名馈赠发布
m92_assembly:
  step1_match_intent:      # 意图匹配（M91 campus_gift_intent 缓存 / 直通）
    - intent: 馈赠
      condition: campus_gift_intent.secret_mode = true
  step2_map_item:          # 物品语境映射（西幻产出物 → 校园匿名馈赠物）
    - from: production_output.item   # M17 payload {recipe_id, item, qty, quality, cost, tick}
      map: 校园等价物（匿名可递送、不暴露异界来源）
      secret: true                   # 去来源化包装（M23 认知边界：校园侧只见馈赠，不见生产链）
  step3_publish:           # 装配完成 → 发布校园匿名礼物事件
    produce: campus_anonymous_gift
    payload: { item: <映射物>, qty: <M17.qty>, quality: <M17.quality>, source_package: 西幻生存领域包, origin: M17->M92, tick: <M17.tick> }
```

## 4 事件契约

- subscribe `production_output`：西幻 M17 生产输出（{recipe_id, item, qty, quality, cost, tick}）→ 触发装配
- publish `campus_anonymous_gift`：校园匿名礼物事件（去来源化 payload），供 P50 交互面/输出生成器消费
- 契约闭合：本模块 subscribe 覆盖 M17 publish（production_output），check16-A ③ 仲裁 pub⊆nsub 无越界

## 5 引用的资产（asset_readonly 借阅，不复制）

本模块无自有资产（assets.count=0）。运行时经 asset_get 借阅源包资产：

- 西幻生存领域包：生产制造素材（M17 关联资产）
- 校园情感领域包：馈赠/匿名礼物呈现素材（经校园面呈现）
