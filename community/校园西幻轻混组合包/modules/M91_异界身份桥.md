# 模块 M91 · 异界身份桥

> 类别：轻混｜来源：校园西幻轻混组合包｜挂载点：P40 行为决策（active）｜编号段：M91-M99 社区预留
> 依赖：M00（数据结构）、M08（季节天气）、M23（认知边界）——官方核心（R1 core_only）
> 发布：`campus_gift_intent`｜订阅：`relationship_change`、`confession_event`、`npc_action`
> 引用装配：校园 M55 匿名情书（confession_event 上游）/ 西幻 M17 生产制造（经 M92 中转收口）
> 对应 protocol.yaml modules[0].id=M91｜模板制作指令包 格式一（八要素）示例落盘

```yaml
machine_contract:
  schema: "1"
```

## 1 职责

轻混决策层（P40）装配模块：在「校园情感表达通道」与「西幻身份秘密」两条语境之间架桥。角色以异界身份生活在校园，情感表达（M55 情书链）与异界身份暴露风险（西幻面 npc_action / 生产痕迹）互相牵制——本模块把冲突转译为**校园语境可执行的馈赠意图** `campus_gift_intent`，交 P50 执行层 M92 装配落地。

## 2 输入输出（八要素）

- 编号：M91（社区预留段，protocol.yaml module_id_range 在册）
- 名称：异界身份桥
- 类别：轻混（组合包独占类别，与源包 [情感]/[生存] 无交集——R2）
- 层：P40 行为决策（active，mount_layers.P40.default=[M91]）
- 输入（订阅）：relationship_change / confession_event（校园面）；npc_action（西幻面）
- 输出（发布）：campus_gift_intent
- 可替换：是（组合包装配位；卸载后 P40 回落源包 M55 单语境决策，不影响源包独立运行）
- 核心逻辑：见 §3

## 3 核心逻辑：三段式轻混决策

```yaml
# 三段式：语境识别 → 身份秘密权衡 → 意图转译
m91_decision:
  step1_context_id:        # 语境识别（事件来源面）
    - source: 校园面         # relationship_change / confession_event
      target: 直通馈赠意图
    - source: 西幻面         # npc_action（身份秘密压力）
      target: 先做暴露风险评估
  step2_secret_tradeoff:   # 身份秘密 × 情感表达（M23 认知边界约束）
    exposure_risk: [低, 中, 高]      # npc_action 越界频度 → 风险档
    expression_gain: [低, 中, 高]    # 关系阶段 × confession_event 强度
    rule: |
      风险=高 且 收益=低 → 压回（不发布，仅记 relationship_change 观察）
      其余 → 转译意图（收益≥风险 或 匿名通道可消化）
  step3_translate:         # 意图转译（西幻动作意图 → 校园匿名馈赠意图）
    produce: campus_gift_intent
    payload: { intent: 馈赠, secret_mode: true, origin: M91, source_event: <原事件> }
```

## 4 事件契约

- subscribe `relationship_change`：校园关系变化（M55 情书链上游），刷新表达收益档
- subscribe `confession_event`：M55 匿名情书事件到达，触发 step2 权衡
- subscribe `npc_action`：西幻 NPC 行动（身份秘密压力面），抬升暴露风险档
- publish `campus_gift_intent`：馈赠意图（携带 secret_mode），P50 层 M92 订阅装配

## 5 引用的资产（asset_readonly 借阅，不复制）

本模块无自有资产（assets.count=0）。运行时经 asset_get 借阅源包资产：

- 校园情感领域包：情书事件链素材（M55 关联资产）
- 西幻生存领域包：身份秘密/异界线索素材（经 npc_action 面）
