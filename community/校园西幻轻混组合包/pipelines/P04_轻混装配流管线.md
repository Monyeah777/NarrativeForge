# 管线 P04 · 轻混装配流管线
> 社区版「校园 × 西幻轻混」组合包使用的管线（v0.8.1 完整战例落盘，C6）。以「异界身份 × 校园日常」的轻混装配为叙事主轴：P40 行为决策位由自带 M91 异界身份桥主导（校园情感表达通道 × 身份秘密权衡），P50 交互执行位由自带 M92 轻混装配执行收口（西幻 production_output → 校园匿名馈赠）。源包模块本体不搬移——校园 M55 / 西幻 M17 仍驻各自源包 default，事件经 references 协议级通道被 M91/M92 订阅装配。
> 实例声明：本管线是通用骨架 **P00**（03_管线库/P00_通用文档生成管线.md）在**叙事领域·轻混装配流**的装配——九层位名沿用骨架；本包仅 P40/P50 两驻留自带模块（M91/M92），其余层为空跑位（由官方核心 + 两源包管线承载，组合包不自建重复模块）。
> **允许编号段固化（R2，v0.8.1）**：本包 `allowed_modules` 仅限官方核心（M00 / 通用:M10 / M06 / M08 / M12 / M13 / M20 / M23 / M24 / M50 / M80 / 事件:M22）与本包题材段（M91 / M92，modules/ 在册 2 件）。references 引用模块（校园 M55 / 西幻 M17）经协议级通道引入（02 §8.4），不占本包 default/available 槽；其余编号一律不得引入。
> **references 装配规避（check15 ③）**：校园 P40 default=[情感:M22, M40, M41, M43, M55]；西幻 P50 default=[M04, M11, M17]。本包 P40 default=[M91] ∩ 校园 P40 = ∅；本包 P50 default=[M92] ∩ 西幻 P50 = ∅——同层 default 无交集，挂载层冲突断言通过。

## 运行规则
- 轻混装配只叠加、不搬移：M55/M17 本体驻源包 default；组合包通过 references 订阅其事件、asset_readonly 借阅其资产（02 §8.4 登记判定四规则）。
- 契约闭合：M92 subscribe 覆盖 M17 publish（production_output），check16-A ③ pub⊆nsub 无越界；M91 publish（campus_gift_intent）为组合包内部事件，不要求源包反向订阅。
- 同层 default 无交集（check15 ③）：本包 P40/P50 只挂 M91/M92，与校园 P40 / 西幻 P50 各自 default 不冲突；两源包可独立运行，组合包可叠加装配（卸载本包不影响源包）。
