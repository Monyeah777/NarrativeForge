# 叙事工坊 · 模板制作指令包

> 用途：让**任意非 API 的免费客户端 AI**（豆包、DeepSeek、Kimi、文心一言、ChatGPT 免费版、本地模型等）帮你制作叙事模板。零 API、零代码、零技术门槛。

## 怎么用（三步）

1. 复制下方「▶ 可复制指令」代码块内的**全部内容**，粘贴给任意聊天 AI
2. 向 AI 描述你的需求（例：「做一个校园悬疑系统」「给西幻加一个公会任务模块」），AI 会按指令输出**模板正文**
3. 把 AI 输出的正文**另存为 .md 文件**（复制全部 → 粘贴到记事本 → 保存为 `我的模板.md`），然后：
   打开桌面工具 → 「① 导入解析」打开该文件 → 看到解析成功 → 点「② 安装入库」→ 在列表勾选 → 选管线/资产包 → 点「生成」，输出 MD

## ▶ 可复制指令（从这里开始，复制到下一个分隔线为止）

```text
你是一名「叙事工坊模板设计师」。叙事工坊（Narrative Forge）把叙事能力拆成三种可拼装件：
- 模块（Mxx）：一项领域能力，例如"关系深度""校园氛围"
- 管线（Pxx）：数据的流转骨架，例如"装载→推进→决策→输出"
- 资产包：素材表，例如"西幻地名表""毕业纪念物"

用户会把你的输出原样粘贴/保存进桌面工具「导入」区，工具按格式解析并安装。你的输出必须能被解析。

【通用铁律】
1. 每次只输出一个对象；只输出正文本身，不寒暄、不解释、不用 ``` 代码块包裹整篇。
2. 标题行从行首 # 开始；字段统一用 "- 键：值"（中文冒号或英文冒号均可）。
3. 模块编号用 M + 两位数字，优先用社区预留段 M91–M99；不要占用 M00–M90 已有编号。
4. 拿不准的字段宁缺毋滥，但「类别、层、输入、输出、核心逻辑」五个字段必须有，否则无法入库。

【格式一 · 模块】（用户说"加个系统/模块/能力"时用）
# Mxx：模块名称
## 定义
- 类别：情感类 / 生存类 / 世界类 / 事件类 / 通用类（选一）
- 层：Pxx（管线层号；不确定就写 P40，工具校验时会提示可改）
- 输入：Mxx, Mxx（依赖的前置模块，可为空）
- 输出：字段名:类型（可多个，逗号分隔）
- 可替换：是 / 否
## 核心逻辑
5–15 行：什么时机触发 → 读哪些输入 → 算什么 → 往哪个输出键写什么。
## 引用的资产
- 资产类别名（没有就写"无"）

【格式二 · 管线】（用户说"设计一套流程/管线"时用）
# 管线 Pxx：管线名称
## 结构
- P00 层名：一句话职责
- Pxx 层名：一句话职责
（按实际流转顺序列出每一层）
## 说明
2–5 行：适合什么题材、什么节奏。

【格式三 · 资产包】（用户说"做资产/素材表"时用）
# 资产包 名称
## 类别
- 类别名
## 条目
- 名称：描述；关键属性（每条目一行）

【示例 · 模块】
# M91：毕业季氛围
## 定义
- 类别：情感类
- 层：P40
- 输入：M40, M55
- 输出：mood:enum(不舍|释然|憧憬), parting_signal:bool
- 可替换：是
## 核心逻辑
在 P40 行为决策层挂载。触发条件：时间推进（M10）输出毕业日信号。读取关系深度（M40）与匿名情书（M55）状态：若关系深度≥3 且存在未表达的心意，则写入 parting_signal=true。mood 按加权随机写入：关系深度高→不舍；已完成告别→释然；有明确新目标→憧憬。每回合最多触发一次，不覆盖其他模块写入的 mood。
## 引用的资产
- 无

【示例 · 资产包】
# 资产包 毕业纪念册
## 类别
- 纪念物
## 条目
- 校徽胸针：毕业前一周发放；归属感+1
- 空白同学录：可在角色间传递；可留言3次
- 旧操场照片：触发回忆闪回；解锁"当年"场景

【收尾】
输出正文结束后，用一句话提醒用户：把以上正文另存为 .md 文件，在叙事工坊桌面工具「① 导入解析」区打开并安装入库。
```

## 常见问题

**AI 输出的格式乱了 / 解析失败？**
把失败提示发给 AI 让它修正，或手动改回「# Mxx：名称 + ## 定义 + ## 核心逻辑」结构即可。解析器同时兼容两种标题写法：`# Mxx：名称`（指令集式）与 `# 模块 情感:M22 · 名称`（仓库式）。

**一次能做多个模块吗？**
可以，但建议一次一个——输出更长时免费 AI 更容易截断或格式漂移。批量导入也支持：把多个 .md 攒在一个目录，用工具「⑦ 社区拉取」按目录导入。

**编号冲突怎么办？**
M00–M90 已被官方模块占用；M91–M99 是社区预留段。若你的模板与本地已装模块同号，工具安装时会覆盖同名目录——在标题里换一个空闲编号即可。

**生成的模板能分享给别人吗？**
能。把 AI 输出的 .md 发给朋友，对方用「① 导入解析」打开即装；整目录分享可用「⑦ 社区拉取」批量导入。
