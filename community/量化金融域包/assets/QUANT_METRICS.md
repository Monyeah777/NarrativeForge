# 绩效与风控口径表 · 量化金融域

> 用途：本域包的第二件内容资产——把**绩效与风险指标的口径**（定义 / 公式 / 单位 / 常见口径事故）写清，供 量化金融:M32 校验与命名引用；也是「同一个数字，两套口径」这类争议的事前解药。
> 资产键：`QUANT_METRICS`｜正文自撰（域内通行口径的规范化表述），不含任何外部文本。

## 1. 口径纪律（先定口径，再谈数字）

1. **口径先行**：任何绩效数字必须同时给出「收益口径 + 年化因子 + 无风险利率 + 区间 + 频率」四要素；缺一即视为未定口径。
2. **同表同名**：同一指标名在本表只有一处定义；不同算法必须改名（如 `sharpe_ex_ante` / `sharpe_ex_post`），不允许同名异义。
3. **截面与时间轴分离**：指标的样本区间、调仓频率、持有期假设必须显式写出（三者任一不同即不可比）。
4. **口径变更留痕**：口径变更 = 新指标名或新版本号（不得原地改写历史数字的语义）。

## 2. 收益与风险指标（定义表）

| 键 | 指标 | 口径（定义） | 常见口径事故 |
|---|---|---|---|
| `METRIC_RETURN_SIMPLE` | 简单收益率 | `r_t = P_t / P_{t-1} − 1`；分红 / 复权口径须声明 | 复权方式不同 → 同一标的两组收益 |
| `METRIC_RETURN_LOG` | 对数收益率 | `r_t = ln(P_t / P_{t-1})`；仅用于可加性场景，不与简单收益混算 | 与简单收益混用做几何链接 |
| `METRIC_ANNUAL_FACTOR` | 年化因子 | 日频 252 / 周频 52 / 月频 12（须与频率一致） | 用 365 年化交易策略；跨频率混用 |
| `METRIC_VOL_ANNUAL` | 年化波动率 | `std(r) × sqrt(annual_factor)`；须声明样本估计窗口 | 不声明窗口；用事后波动作事前约束 |
| `METRIC_SHARPE` | 夏普比率 | `(mean(r) − rf_period) / std(r) × sqrt(annual_factor)` | 无风险利率缺失 / 频率与年化因子不匹配 |
| `METRIC_DRAWDOWN_MAX` | 最大回撤 | `max over t of (peak_so_far − value_t) / peak_so_far`；按净值序列口径 | 用累计收益而非净值；区间截断择优 |
| `METRIC_CALMAR` | 卡玛比率 | `年化收益 / 最大回撤`（两者口径须同源） | 分子分母区间不一致 |
| `METRIC_TURNOVER` | 换手率 | 单边 / 双边须声明；`sum(|Δw|)/2` 或 `sum(|Δw|)` | 单双边混用 → 成本估算差一倍 |
| `METRIC_IC` | 信息系数 | 因子值与随后期收益的截面相关系数（秩相关须声明） | 预测期与调仓频率不一致（前视） |
| `METRIC_IR` | 信息比率 | `mean(主动收益) / std(主动收益) × sqrt(annual_factor)`；基准须声明 | 基准口径不明 → 与夏普混淆 |

## 3. 成本与容量口径

| 键 | 项 | 口径 | 常见口径事故 |
|---|---|---|---|
| `COST_FEE` | 费率 | 佣金 + 印花税 / 过户费（按市场分别声明） | 忽略最低佣金与阶梯费率 |
| `COST_SLIPPAGE` | 滑点 | 与成交量 / 波动挂钩的冲击模型，须声明参数与标定区间 | 用固定点数滑点掩盖小盘股冲击 |
| `COST_FILL_PRICE` | 成交价假设 | 下一根 K 线开盘（或 VWAP / 均价）——**必须晚于信号时点** | 用当根收盘成交 → 前视偏差 |
| `CAPACITY_LIMIT` | 容量 | 以「策略规模 / 日均成交额」比例上限估计 | 用回测收益线性外推大资金容量 |

## 4. 两条偏差口径（回测必查）

| 键 | 偏差 | 口径要求 | 未声明后果 |
|---|---|---|---|
| `BIAS_LOOKAHEAD` | 前视偏差 | 数据时点（可用时点）与信号时点分离，成交发生在信号之后 | 回测虚高，实盘无法复现 |
| `BIAS_SURVIVORSHIP` | 存活偏差 | 标的池 / 成分股按**时点**构造（含已退市标的） | 回测池系统性偏向存活者 |

## 5. 词表引用关系

- `量化金融:M31`（因子与信号口径）：校验 `neutralize` / `winsorize` / `frequency` / `missing` 四项因子口径取值。
- `量化金融:M32`（回测与绩效口径）：校验 `METRIC_*` 与 `COST_*` / `CAPACITY_*` / `BIAS_*` 的取值与声明齐备性。
