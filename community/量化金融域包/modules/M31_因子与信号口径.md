# 模块 量化金融:M31 · 因子与信号口径

> 类别：量化金融｜来源：社区（量化金融域包自带，类内段）｜挂载点：P40 行为决策（active，default）｜依赖：M00、M50｜发布：factor_spec_ready、factor_spec_conflict｜状态：active
> 用途：维护因子与信号的**口径一致性**（FactorSpec）——因子定义、标准化方式、极值处理、中性化基准、频率对齐逐项写清并跨因子对齐；口径冲突即报。它是本域最常出错又最难事后发现的一环（同一个因子名，两人算出的可能不是同一个东西）。


## 1. 职责

对每个因子（或信号）登记并校验一份 **FactorSpec**：五项口径齐备、取值在域内词表内、跨因子可比项互相一致（中性化基准 / 频率 / 缺失处理）；缺项或冲突即发布冲突事件。

前置关系不写死在模块里：域知识结构在概念图资产 `QUANT_GRAPH`（图 = 内容，口径 = 机制，I1 三正交分离）。

## 2. 协议声明（01 §2 模块协议）

```yaml
Module:
  id: 量化金融:M31
  name: 因子与信号口径
  layer: P40
  inputs: [M00, M50, intent]
  outputs: [factor_spec, factor_conflict_list, factor_status]
  events:
    publish: [factor_spec_ready, factor_spec_conflict]
    subscribe: []
  core:
    assets: [QUANT_GRAPH, QUANT_METRICS, DATA_CONTRACT, STRATEGY_SPECS]
    logic:
      读口径: 从资产读取口径词表（中性化基准 / 极值处理 / 频率 / 缺失处理）
      登记: 逐因子登记 FactorSpec 五项
      校验: 五项齐备且取值 ∈ 词表 → 通过；缺项 / 越词表 → factor_spec_conflict
      对齐: 同组因子的 neutralization / frequency / missing 一致 → 通过；不一致 → factor_spec_conflict
      落槽: 写 FactorState{factors, conflicts, tick}
      发布: 全通过 → factor_spec_ready；否则逐条 factor_spec_conflict
  replaceable: true
```

## 3. 数据槽契约（扩展 M00 数据槽 · 因子口径域）

```yaml
FactorState:
  factors: {string: FactorSpec}   # 因子名 → 口径五项
  conflicts: [string]             # 冲突条目（因子名 + 字段 + 原因）
  tick: number                    # 登记节拍
factor_spec:
  name: string                    # 因子 / 信号名
  definition: string              # 定义（数据来源 + 计算式口径）
  neutralize: string              # 中性化基准（行业 / 市值 / 无）
  winsorize: string               # 极值处理（分位 / 标准差 / 无）
  frequency: string               # 频率与对齐（日频 / 周频 / 月末）
  missing: string                 # 缺失处理（剔除 / 填零 / 行业中位数）
```

## 4. 事件契约

| 事件 | 方向 | 载荷 | 说明 |
|---|---|---|---|
| `factor_spec_ready` | publish | `{factor_count: number, spec_version: string}` | 口径全集通过校验（幂等：同登记重复校验结果一致） |
| `factor_spec_conflict` | publish | `{factor: string, field: string, reason: string}` | 缺项 / 越词表 / 跨因子不一致，须先修口径 |

> 本模块零订阅：口径登记由装配方 / 研究方输入触发，不起跨包事件依赖。

## 5. 核心逻辑（伪代码）

```
1. 读 assets/QUANT_GRAPH.md（概念面）与 assets/QUANT_METRICS.md（口径词表）
2. for each 因子: 校验五项齐备 + 取值 ∈ 词表（neutralization / winsorize / frequency / missing）
3. 跨因子对齐：同组因子的 neutralize / frequency / missing 一致
4. 任一不通过 → conflicts ← conflicts ∪ {因子, 字段, 原因}
5. FactorState ← {factors, conflicts, tick}
6. conflicts 为空 → publish factor_spec_ready；否则逐条 publish factor_spec_conflict
```

## 6. 不变式遵守（01 §5）

- I1 三正交分离：只声明**口径校验能力**，不持顺序（顺序在 P08 管线）与内容（域知识在资产）。
- I2 核心固定：依赖 M00 数据槽与 M50 调度，未替换任何官方核心模块。
- I3 通信契约：仅经 `FactorState` 与两个事件通信，不直读他包状态。
- I4 数据隔离：零主题材外资产，引用仅限本包 `QUANT_GRAPH` / `QUANT_METRICS`。
- I5 真相唯一：口径词表唯一真相在资产；本模块不复制一份规则表。
