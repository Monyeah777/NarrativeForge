# 模块 量化金融:M32 · 回测与绩效口径

> 类别：量化金融｜来源：社区（量化金融域包自带，类内段）｜挂载点：P60 长期演变（active，default）｜依赖：量化金融:M31、M00｜订阅：factor_spec_ready、factor_spec_conflict｜发布：backtest_spec_ready、backtest_spec_conflict｜状态：active
> 用途：维护**回测与绩效口径**（BacktestSpec）——成本与成交假设、样本外切分、指标口径（年化因子 / 无风险利率 / 回撤定义 / 换手口径）逐项写清；并做两条最贵的事前检查：**前视偏差**与**存活偏差**的口径是否被显式声明。口径冲突即报，不外放未定口径的绩效数字。

## 1. 职责

1. 订 `factor_spec_ready` / `factor_spec_conflict`（量化金融:M31 发布）→ 因子口径结论并入回测口径的前提集；
2. 登记并校验 **BacktestSpec**：成本与成交假设（费率 / 滑点 / 成交价假设）、样本外切分（训练 / 验证 / 测试边界）、指标口径（年化因子 / 无风险利率 / 回撤定义 / 换手）；
3. 两条偏差口径检查：**前视偏差**（数据时点与信号时点是否分离）与**存活偏差**（标的池 / 成分股是否时点化）；
4. 全通过发布 `backtest_spec_ready`；缺项 / 冲突逐条发布 `backtest_spec_conflict`。

## 4. 事件联动

- subscribe `factor_spec_ready`（量化金融:M31 发布）：因子口径通过 → 并入前提集，继续回测口径校验。
- subscribe `factor_spec_conflict`（量化金融:M31 发布）：因子口径未定 → 记阻断项，不外放绩效口径结论。
- publish `backtest_spec_ready`：回测与绩效口径收敛（幂等：同登记重复校验结果一致）。
- publish `backtest_spec_conflict`：缺项 / 越词表 / 偏差口径未声明。

## 5. 核心逻辑（伪代码）

```
1. on factor_spec_ready / factor_spec_conflict → 更新前提集与阻断项
2. 若阻断项非空 → publish backtest_spec_conflict（原因=因子口径未定）并停在本步
3. 登记 BacktestSpec 三块：成本与成交假设 / 样本外切分 / 指标口径
4. 指标口径取值 ∈ assets/QUANT_METRICS.md 词表；越词表 → 冲突
5. 偏差口径检查：lookahead / survivorship 未声明 → 冲突（阻断）
6. conflicts 为空 → publish backtest_spec_ready；否则逐条 publish backtest_spec_conflict
```

## 6. 不变式遵守（01 §5）

- I1 三正交分离：只承担**回测与绩效口径**，不持因子定义（M31）与域知识（资产）。
- I2 核心固定：依赖 M31 与本包资产，官方核心件（M00/M50/M80）不动。
- I3 通信契约：仅经 `BacktestSpec` 与两个事件通信。
- I4 数据隔离：零新增资产，只读本包两件资产（不复制内容）。
- I5 真相唯一：指标词表唯一真相在 `QUANT_METRICS`。
