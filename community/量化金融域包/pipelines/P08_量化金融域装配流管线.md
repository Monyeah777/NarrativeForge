# 管线 P08 · 量化金融域装配流
> 社区版「量化金融域包」使用的管线（第 3 个非叙事域战例落盘）。以「口径先行」为流主轴：官方核心 M00 数据槽（P00 位）承载口径登记状态，通用:M10 节拍（P10 位）给口径登记定拍，M50 主循环（调度器，无层挂载）在回卷点推进下一回合；本包自带 量化金融:M31 挂 P40 位做**因子与信号口径**（FactorSpec 五项 + 跨因子对齐），量化金融:M32 挂 P60 位做**回测与绩效口径**收口（成本与成交假设 / 样本外切分 / 指标口径 + 前视与存活偏差口径检查）；P80 输出呈现仍由官方核心 M80 质检渲染（gate 唯一出口，同其它流）。
> 实例声明：本管线是通用骨架 **P00**（03_管线库/P00_通用文档生成管线.md）在**量化金融·口径协议**的实例——九层位（P00–P80）名沿用骨架；本包 P40/P60 两驻留自带模块（量化金融:M31/M32），其余层位由官方核心承载，本包不自建重复模块（I5 单一真相源，官方模块文件不复制进包）。
> **允许编号段固化（R2）**：本包 `allowed_modules` 只含官方核心承载件与本包类内段编号——P00 数据基座 M00 / P10 世界推进 通用:M10 / P20 角色状态 M23 / P30 事件生产 事件:M22·M06·M13 / P40 行为决策 **量化金融:M31** / P50 交互执行 M12 / P60 长期演变 **量化金融:M32** / P70 叙事素材 M20·M24 / P80 输出呈现 M80；M50 主循环为全局调度器（无层挂载），以 core 依赖引用参与回卷。references=[] 零跨包零借阅——其余编号一律不得引入。
> **挂载层规避（check15 ③）**：官方骨架 P00 九层 default 均空；既有社区包同层 default（校园 P40=[情感:M22,M40,M41,M43,M55]、P60=[M40,M65]；西幻 P40=[M04,M11]、P60=[生存:M10,M07,M09,M14,M15,M16]；技术文档 P40=[M97]、P60=[M98]；AI系统 P40=[AI系统:M25]、P60=[AI系统:M26]）与本包 P40=[量化金融:M31]、P60=[量化金融:M32] 无交集——类内段新编号唯一，独立装载不冲突（卸载本包不影响官方核心与既有包）。

## 运行规则
- 只叠加、不搬移：官方核心配合件（M00 / 通用:M10 / M23 / M50 / M80，以及空跑层位的 M06/M13/M12/M20/M24/事件:M22）本体驻官方核心层位；本包以 core_only 依赖引用协作，**禁止**复制官方模块文件入本包 modules/ 或写入官方层 default 槽（I5 单一真相源）。
- 契约闭合：量化金融:M31 零订阅（口径登记由输入触发）；量化金融:M32 subscribe（factor_spec_ready / factor_spec_conflict）⊆ 量化金融:M31 publish——本包内发布/订阅自洽无越界（check16 ③ 语义的同包形态）。
- 同层 default 无交集（check15 ③）：本包 P40 只挂 量化金融:M31、P60 只挂 量化金融:M32；官方骨架各层 default 为空、既有社区包同层 default 无本包编号——独立装载不冲突。
- 概念前置求值**不由本包模块承担**：图资产 `QUANT_GRAPH` 由只读求值器（`--asset`）与 verify check32 的 `concept_graph` 子扫描消费（机制复用，避免每域复制一套闭包算法）；模块级闭包事件 / 数据槽仍是 AI系统域包私有，跨域复用须先裁决参数化（见 `results/audit/docs_audit-55-quant-domain.md` §三）。
- 本包 references=[] 恒空（零跨包零借阅）；后续包可经 references 协议级通道引用本包模块（届时按 02 §8.4 组合登记另立装配）。
