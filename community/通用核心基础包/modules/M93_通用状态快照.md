> 类别：通用｜来源：通用核心基础包｜挂载点：P00 数据基座（active）｜编号段：M91-M99 社区预留
> 依赖：M00（数据结构）、通用:M10（时间推进）——官方核心（R1 core_only）
> 发布：`state_snapshot`｜订阅：`tick_day`、`minute_tick`（通用:M10 节拍源）
> 引用装配：无跨包引用（references=[]，v2 白名单恒空；通用类整包零借阅）

## 1 职责

数据基座层（P00）装配模块：题材无关的核心状态收敛器。订阅通用:M10 节拍事件（`tick_day` / `minute_tick`），在每个节拍把四类核心实体——角色（源自 M00 数据槽）、世界（M08 季节天气）、时间（M10 节拍）、剧情（M06 任务态）——收敛为**统一快照** `state_snapshot`，作为 P40 层 M95 决策汇总的基座上下文。本模块不产题材内容，只做「节拍到快照」的通用收敛（M00 本体仍驻官方核心 P00 数据槽，本模块为数据槽之上的快照机制增强）。
## 2 输入输出（八要素）
- 编号：M93（社区预留段，protocol.yaml module_id_range 在册）
- 名称：通用状态快照
- 类别：通用（通用类整包独占类别，与既有 [情感]/[生存]/[世界]/[事件]/[轻混] 无交集——R2）
- 层：P00 数据基座（active，mount_layers.P00.default=[M93]）
- 输入（订阅）：tick_day / minute_tick（通用:M10 节拍广播）
- 输出（发布）：state_snapshot
- 可替换：是（通用装配位；卸载后 P00 回落官方 M00 纯数据槽，领域包可自带题材快照模块替代）
- 核心逻辑：见 §3
## 3 核心逻辑：三段式状态收敛
```yaml
# 三段式：节拍触发 → 四域收敛 → 快照封装
m93_snapshot:
  step1_beat_trigger:     # 节拍触发（订阅通用:M10）
    - on: tick_day         # 日节拍 → 全量快照
      target: 收敛四域
    - on: minute_tick      # 分钟节拍 → 增量快照（仅变更域）
      target: 收敛变更域
  step2_four_domain:      # 四类核心实体收敛（M00 数据槽读取）
    actor: 角色态          # 位置/状态/关系阶段
    world: 世界态          # M08 季节天气 + 环境标记
    time: 时间态           # 当前 tick/日/时刻（M10 折算）
    plot: 剧情态           # M06 quest_state 最新档
  step3_snapshot_pack:    # 快照封装（统一结构，供 P40 决策基座）
    produce: state_snapshot
    payload: { domain: [actor, world, time, plot], tick: <当前节拍>, origin: M93, mode: full|delta }
```
## 4 事件契约
- subscribe `tick_day`：通用:M10 日节拍广播，触发全量四域收敛
- subscribe `minute_tick`：通用:M10 分钟节拍广播，触发变更域增量收敛
- publish `state_snapshot`：统一状态快照（携带 domain/tick/mode），P40 层 M95 订阅作决策基座
