> 类别：通用｜来源：通用核心基础包｜挂载点：P80 输出呈现（active）｜编号段：M91-M99 社区预留
> 依赖：M80（输出生成器）、事件:M22（事件叙事）——官方核心（R1 core_only）；本包 M95 事件
> 发布：`polished_output`｜订阅：`narrative_event`（官方事件:M22）、`decision_brief`（本包 M95）
> 引用装配：无跨包引用（references=[]，v2 白名单恒空；通用类整包零借阅）

## 1 职责

输出呈现层（P80）装配模块：题材无关的输出润色器。订阅官方事件:M22 的叙事唯一输入门事件 `narrative_event`（M80 输出生成器的上游输入），结合本包 M95 决策简报 `decision_brief` 做**叙事一致性预检与通用润色**（去重、时序对齐、语境补全），发布 `polished_output`。本模块是 M80 的机制增强（挂在官方 P80 输出层之上），**非替代 M80**——M80 本体仍驻官方核心 P80 默认装配位，本模块只做输出门的通用前置润色，不产题材文风（领域包 DNA 文风仍由题材包自带润色层实现）。
## 2 输入输出（八要素）
- 编号：M96（社区预留段，protocol.yaml module_id_range 在册）
- 名称：通用输出润色
- 类别：通用（通用类整包独占类别——R2）
- 层：P80 输出呈现（active，mount_layers.P80.default=[M96]）
- 输入（订阅）：narrative_event（官方事件:M22 叙事输入门）；decision_brief（本包 M95 决策简报）
- 输出（发布）：polished_output
- 可替换：是（通用装配位；卸载后 P80 回落官方 M80 原样输出，领域包可自带题材润色模块替代）
- 核心逻辑：见 §3
## 3 核心逻辑：三段式输出润色
```yaml
# 三段式：叙事捕获 → 一致性预检 → 通用润色
m96_polish:
  step1_capture:          # 叙事捕获（订阅官方事件:M22 narrative_event）
    input: narrative_event      # M80 输出门上游唯一输入
    with: decision_brief        # 本包 M95 决策简报（对齐基准）
  step2_precheck:         # 一致性预检（叙事 vs 决策简报）
    checks:
      - 事件与决策简报 round 对齐（无跨回合串线）
      - 语境补全（缺失的上下文占位标记，不臆造题材内容）
      - 重复叙事段折叠
  step3_polish:           # 通用润色（去题材化：只做结构润色不作文风注入）
    produce: polished_output
    payload: { source: narrative_event, aligned: decision_brief, origin: M96, style: 通用（题材文风由领域包覆盖） }
```
## 4 事件契约
- subscribe `narrative_event`：官方事件:M22 叙事事件（M80 输出门输入），触发润色流程
- subscribe `decision_brief`：本包 M95 决策简报，作为叙事一致性预检的对齐基准
- publish `polished_output`：通用润色后输出（携带 source/aligned 元信息），供领域包题材润色层接力或直出
