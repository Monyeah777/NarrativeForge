## 1 职责

世界推进层（P10）装配模块：题材无关的节拍折算桥。订阅通用:M10 的 `tick_day` / `minute_tick` 原始节拍，折算为**统一节拍流** `beat_tick`（含 tick/day/minute 换算与节拍缓冲队列），供 P40 层 M95 及领域包决策模块按统一节拍消费。领域包可把 `beat_tick` 折算进自身时间制（校园课表节、西幻历法日），本模块只做通用折算不产题材历法（M10 本体仍驻官方核心 P10，本模块为其节拍之上的缓冲/折算机制增强）。
## 2 输入输出（八要素）

- 核心逻辑：见 §3
## 3 核心逻辑：三段式节拍桥
```yaml
# 三段式：节拍折算 → 缓冲队列 → 节拍广播
m94_beat_bridge:
  step1_convert:          # 节拍折算（订阅通用:M10 原始节拍）
    tick_to_minute: 1 tick = 1 minute_tick  # 官方基准换算
    day_to_tick: 1 tick_day = N minute_tick   # 日节拍折算到分钟节拍
    output: { base: minute_tick, derived: [tick_day, tick] }
  step2_buffer:           # 节拍缓冲队列（防抖/对齐，供决策回合消费）
    queue: [<折算后节拍>]
    rule: |
      同一决策回合内到达的多个原始节拍 → 合并为单次 beat_tick
      跨回合边界 → 新起缓冲段，旧段封口广播
  step3_broadcast:        # 统一节拍广播
    produce: beat_tick
    payload: { tick: <折算值>, day: <日计数>, minute: <分钟计数>, origin: M94, buffered: true }
```
## 4 事件契约
- subscribe `tick_day`：通用:M10 日节拍广播，折算并入缓冲队列
- subscribe `minute_tick`：通用:M10 分钟节拍广播，折算并入缓冲队列
- publish `beat_tick`：统一折算节拍（携带 tick/day/minute），P40 层 M95 与领域包决策模块按统一节拍消费
