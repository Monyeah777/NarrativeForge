## 5. 运行约束（红线）
- **只依赖、不搬移**：官方核心 12 件本体驻官方核心层位 default；本包 core_only 依赖引用 + 事件订阅协作——**禁止**将官方模块复制入本包 modules/ 或写入官方层 default/available 槽（I5 单一真相源）。
- **契约闭合**：M93/M94 subscribe（tick_day/minute_tick）⊆ 通用:M10 publish；M95 subscribe（quest_state/interaction_update/state_snapshot/beat_tick）⊆ M06/M13/M93/M94 publish；M96 subscribe（narrative_event/decision_brief）⊆ 事件:M22/M95 publish——check16 ③ pub⊆nsub 无越界。
- **同层 default 无交集**（check15 ③）：本包 P00/P10/P40/P80 只挂 M93/M94/M95/M96，官方骨架各层 default 为空、既有领域包同层 default 无 M93-M96——独立装载互不冲突；卸载本包不影响官方核心与既有包。
- **编号段红线**（R2）：本包模块限 M93-M96（M91-M99 社区预留段）；不得引入官方核心未列模块编号入 default/available。
- **数据隔离**：本包不自建存档键；官方核心键由官方核心流程读写，本包只读官方事件流，不跨写官方存档。
- **零跨包**：references=[] 恒空；本包不订阅任何源包（校园/西幻）事件，不借阅其资产。
