# 管线 P05 · 核心基础流管线
> 社区版「通用核心基础包」使用的管线（v1.1.0 通用类整包战例落盘）。以「题材无关的通用机制增强」为叙事主轴：P00 数据基座位由自带 M93 通用状态快照主导（订阅 通用:M10 节拍，收敛角色/世界/时间/剧情四域为 state_snapshot），P10 世界推进位由自带 M94 通用节拍桥主导（同源节拍折算 tick/day/minute + 缓冲队列，发布 beat_tick），P40 行为决策位由自带 M95 通用决策汇总收口（聚合官方 M06 quest_state / M13 interaction_update 与本包 state_snapshot / beat_tick 为 decision_brief），P80 输出呈现位由自带 M96 通用输出润色收口（订阅官方 事件:M22 narrative_event 与 decision_brief，做一致性预检与通用润色，发布 polished_output）。官方核心模块本体不搬移——M00 / 通用:M10 / M80 等 12 件仍驻官方核心层位（core_only 依赖引用，I5 单一真相源），本包只订阅其事件流协作。
> 实例声明：本管线是通用骨架 **P00**（03_管线库/P00_通用文档生成管线.md）在**通用·核心基础流**的装配——九层位名沿用骨架；本包 P00/P10/P40/P80 四驻留自带模块（M93/M94/M95/M96），其余层为空跑位（由官方核心承载，本包不自建重复模块）。
> **允许编号段固化（R2，v1.1.0）**：本包 `allowed_modules` 仅限官方核心（M00 / 通用:M10 / M06 / M08 / M12 / M13 / M20 / M23 / M24 / M50 / M80 / 事件:M22）与本包通用段（M93 / M94 / M95 / M96，modules/ 在册 4 件）。本包 references=[] 零跨包零借阅，不引入任何源包模块；其余编号一律不得引入。
> **挂载层规避（check15 ③）**：官方骨架 P00 九层 default 均空（03_管线库/P00_通用文档生成管线.md layers 实况）；既有领域包同层 default 不含 M93-M96。本包 P00 default=[M93] / P10 default=[M94] / P40 default=[M95] / P80 default=[M96]——同层 default 无交集，独立装载不冲突；卸载本包不影响官方核心与既有包。

## 运行规则
- 通用增强只叠加、不搬移：官方核心 12 件（M00 / 通用:M10 / M08 / M23 / 事件:M22 / M06 / M12 / M13 / M20 / M24 / M50 / M80）本体驻官方核心层位；本包以 core_only 依赖引用 + 事件订阅协作，**禁止**复制官方模块文件入本包 modules/ 或写入官方层 default 槽（I5 单一真相源）。
- 契约闭合：M93/M94 subscribe（tick_day/minute_tick）⊆ 通用:M10 publish；M95 subscribe（quest_state/interaction_update/state_snapshot/beat_tick）⊆ M06/M13/M93/M94 publish；M96 subscribe（narrative_event/decision_brief）⊆ 事件:M22/M95 publish——全链 publish⊆subscribe 自洽无越界（check16 ③）。
- 同层 default 无交集（check15 ③）：本包 P00/P10/P40/P80 只挂 M93/M94/M95/M96，官方骨架各层 default 为空、既有领域包同层 default 无 M93-M96——独立装载不冲突，卸载本包不影响官方核心。
- 本包为通用类整包（references=[] 恒空，零跨包零借阅），题材无关；后续领域包可经 references 协议级通道引用本包模块（届时按 02 §8.4 组合登记另立装配）。
