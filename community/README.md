# 叙事工坊 · 社区版指南

社区版是**免费、零 API、零代码**的桌面工具（Windows exe / macOS / Linux，GitHub Releases 下载，双击即用）。勾选模块 → 选管线 → 选资产包 → 生成 MD → 交给任意 AI 前端开始叙事。

## 一条主线：自制模板的完整闭环

叙事工坊的仓库是「规范库」（01–07 号文档），社区版工具是「装配台」。任何人都可以**不写一行代码**做出自己的模板：

```
你的 GitHub 界面
   │  ① 下载/复制「模板制作指令包」（community/模板制作指令包.md）
   ▼
任意非 API 的免费客户端 AI（豆包 / DeepSeek / Kimi / 文心一言 / ChatGPT 免费版…）
   │  ② 把指令整段粘贴给 AI，说出你的需求（如"做个校园悬疑系统"）
   │  ③ AI 按指令格式输出模板正文，另存为 .md 文件
   ▼
桌面工具（社区版 exe）
   │  ④ 「① 导入解析」打开该 .md → 解析校验 → 「② 安装入库」
   │  ⑤ 勾选模板模块 → 选管线 → 选资产包
   ▼
输出 MD 文件
   │  ⑥ 发给任意 AI 前端 / SillyTavern 等 → 开始叙事
```

## 快速开始（开箱即用，不做模板）

1. 去仓库 **Releases** 页下载对应平台的成品（`NarrativeForge-windows-x64` / `-macos` / `-linux`，由 GitHub Actions 自动构建）
2. 双击运行；首次启动在 `~/.NarrativeForge/` 建好数据目录
3. 勾选预装模块 → 选管线（极简 / 标准 / 校园 P02 / 西幻 P03…）→ 选资产包 → 点「生成」，得到 MD
4. 把 MD 发给你的 AI 前端（SillyTavern / 豆包等）即开跑

> 还没有 Release？仓库正在做首次 CI 构建，作者推送 `v*` 标签后即出包。临时可用源码运行：`cd desktop && pip install PySide6 && python main.py`

## 进阶玩法

- **导入他人模板**：拿到别人分享的模块 .md / module.json 目录 → 工具「⑦ 社区拉取」批量导入
- **预设分享**：把勾选组合存为 .nfpreset 导出，别人导入即可加载
- **定制规范**：仓库 01–07 号文档是协议的完整定义，进阶用户可直接手写模块后导入

## 双版本说明

- **社区版（本指南）**：免费轻量，勾选组装 → 输出 MD。模板由你自己用任意客户端 AI 生成后导入。
- **完整版（规划中）**：社区版全部功能 + 工具内 Agent 对话（自动生成模块 / 自动装配）+ MCP 集成，面向有 API 额度的进阶用户。数据格式与社区版完全互通，社区版数据可直接迁移。
