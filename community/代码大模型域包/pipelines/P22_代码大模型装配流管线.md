# 管线 P22 · 代码大模型装配流

> 社区版「代码大模型域包」使用的管线（域包工厂生成；派生自 P00 通用骨架，九层位名沿用骨架）。以「口径先行」为流主轴：官方核心 M00 数据槽承载口径状态，通用:M10 节拍定拍，M50 主循环在回卷点推进；本包自带 代码大模型:M01 挂 P40 做**口径登记**，代码大模型:M02 挂 P60 做**收口与派生**；P80 输出呈现由官方核心 M80 承担（gate 唯一出口）。
> **允许编号段固化（R2）**：本包 `allowed_modules` 只含官方核心承载件与本包类内段编号；references=[] 零跨包零借阅。
> **挂载层规避**：本包 P40/P60 default 用的是类内段唯一编号，与既有各包同层 default 无交集（独立装载不冲突）。

      default_modules: []
      allowed_modules: [M23]
    - id: P30
      name: 事件生产

## 说明

- 九层位名与 P00 骨架一致；本域只在 P40/P60 驻留自有模块，其余层位由官方核心承载。
- M50 主循环是全局调度器（无层挂载），以 core 依赖引用参与回卷。
- 本管线为域包工厂生成件：`nf domain build --spec A09`（幂等，重跑逐字节一致）。
