## 1. 职责

把口径面收口为**可复算产出**：由样例与度量族重算域报告（T4），并从概念图派生图形态；报告与图与口径表三段同源，任一漂移即发布收口冲突事件。

域知识结构不写死在模块里：概念前置在资产 `CONCEPT_GRAPH`，口径在资产 `DOMAIN_SPEC`（图 = 内容，口径 = 机制，三正交分离）。

## 2. 协议声明（01 §2 模块协议）

```yaml
Module:
  id: 视频生成与剪辑:M02
  name: 视频生成与剪辑收口与形态派生
  layer: P60
  inputs: [M00, M50, '视频生成与剪辑:M01']
  outputs: [domain_report, closure_conflict_list]
  events:
    publish: [e08_report_ready, e08_report_conflict]
    subscribe: [e08_spec_ready, e08_spec_conflict]
  core:
    assets: [DOMAIN_SPEC, CONCEPT_GRAPH]
    logic:
      读口径: 读 视频生成与剪辑:M01 的口径状态（spec 齐备才继续）
      复算: 由 samples/CASES.csv 按度量族重算域报告（core/domain_metrics）
      对齐: 报告字段 ⊆ 口径表条目键；对不上 → e08_report_conflict
      派生: 由 CONCEPT_GRAPH 派生分层图（Mermaid / GraphML）
      发布: 全部一致 → e08_report_ready；否则 e08_report_conflict
```

## 3. 产出面（可机验）

| 产出 | 形态 | 档位 | 说明 |
|---|---|---|---|
| `outputs/DOMAIN_SPEC.json` | 结构化数据 | T3 | 口径表机读投影（与资产双源一致） |
| `outputs/REPORT.json` | 可复算报告 | T4 | 度量族重算（check32 逐字段比对） |
| `outputs/charts/*.vega.json` | 图表规格 | T3 | 由报告确定性生成 |
| `outputs/CONCEPT_DAG.graphml` 等 | 图结构 | T3 | 由概念图确定性派生 |

## 4. 事件联动（机读契约）

```yaml
event: e08_report_ready
payload: { family: string, metrics: number, tick: number }
description: 度量复算完成且与口径表同源
```

```yaml
event: e08_report_conflict
payload: { field: string, reason: string, blocking: boolean }
description: 复算结果与在盘报告不一致 / 报告字段越口径表
```

## 5. 边界与不宣称

- 本模块**不产出模型能力结论**：报告是样例集上的口径值，不是能力评测结论。
- 外部锚只作口径参照，不作质量背书；口径表正文自撰。
- 域包不承担该域的教学职能：包外前置族（E08-00）须装载方自备。
