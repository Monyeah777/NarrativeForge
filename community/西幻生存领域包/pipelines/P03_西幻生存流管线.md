# 管线 P03 · 西幻生存流管线
> 社区版“西幻预设”使用的管线。以职业成长与生存冒险为主轴：世界推进按分钟制结算生存消耗，事件生产产出任务与混沌事件，交互执行承载战斗/魔法/生产/对话，长期演变结算经济/阵营/帮派/建筑。
> 实例声明：本管线是通用骨架 **P00**（03_管线库/P00_通用文档生成管线.md）在**叙事领域·西幻生存流**的装配——九层位名与模块挂载为领域特化。
```yaml
Pipeline:

  name: 西幻生存流管线
  structure:
    type: linear
    flow:
      - from: P00
        to: P10
      - from: P10

      - from: P20
        to: P30
      - from: P30
        to: P40
      - from: P40
        to: P50
      - from: P50
        to: P60
      - from: P60
        to: P70
      - from: P70
        to: P80
      - from: P80
        to: P00

      allowed_modules: [M00, M20]

      allowed_modules: [通用:M10, M08]

      allowed_modules: [M04, M11, M12, M13, M17]
```

## 运行规则
- 生存结算以分钟为单位：health/hunger/thirst/fatigue/temperature/insanity 六项状态由 M01 统一结算。
- 混沌事件可能直接调用生存:M10 死亡判定；死亡不结束游戏，进入重生流程（死亡祝福/遗物继承）。
- 经济结算以 1金=100银=10000铜 为基准，M09 为唯一货币结算入口。
