## 4. 运行规则速查
- 生存六维 vitals{health,hunger,thirst,fatigue,temperature,insanity} 由 M01 统一按分钟结算（10 分钟刻）；health=0 → 交生存:M10 死亡判定。
- 死亡不结束游戏：进入重生流程（死亡祝福/遗物继承）。
- 经济基准 1金=100银=10000铜，M09 为唯一货币结算入口。
- 混沌事件可直接调用死亡判定；insanity≥80 → 幻觉事件（事件:M22 编剧）。
- v0.7.13 认知边界：叙事过四层管线（M00 → 事实 → 快照 → M23 裁剪 → 渲染 → 锚点回验），M23 以 P20 allowed 接入。
## 5. 运行约束（红线）
- **依赖边界（R1）**：本包模块不得跨包依赖校园情感领域包；题材件一律只依赖官方核心层。
- **数据隔离**：存档键 attributes+vitals / economy / relations / death_blessings / 世界档案 仅本包流程可读写；与校园包存档键（relationships 等）**不可互载**，切换预设须开新档。
- **混装拦截**：校园资产键混入本包流程触发 L3 资产可达校验失败——拒绝开跑。

1. **系统提示/角色卡**：把 01_核心协议 → 02_联动注册表（§6 顺序）→ 06_Agent执行协议 → 本 README §2 装载清单，按序写入系统提示；角色卡按建档装载默认状态（attributes+vitals / economy / relations）。

3. **正则与扩展**：挂隐藏域/系统数值剥离正则（防泄漏）；骰子/事件判定可由扩展接 asset_roll(seed)。
