### 1. 任务叙事模板结构（quest_narratives，8个任务）

- 三阶段叙事文本：accept（接受）→ progress（进行）→ complete（完成），各阶段含2条备选表述供随机选用
- target（目标描述）+ reward（奖励内容）驱动任务状态机
- 8任务总览：

### 2. 任务叙事生成规则
- 生成接口：`_generate_quest_narrative(context)`——按 quest_id + stage（accept/progress/complete）从 quest_narratives 字典取文本；stage 缺失返回空串
- 文学风格：LITERARY 样式下应用 `_apply_literary_style(text, "quest")`：①词汇替换（word_replacements 普通→文学表达）②诗意前缀/后缀 30%概率插入 ③文学短语库（literary_phrases[quest]）20%概率插入
- 注册接口：`generate_narrative` 按 NarrativeType 分发——LOCATION / NPC_DIALOGUE / EVENT / FRAGMENT / COMBAT / SKILL / QUEST / DEATH 八类
- 风格切换：`set_narrative_style(style_name)`（玩家命令如 `/style literary`）
- 数据加载：NarrativeManager 初始化加载 location_descriptions / npc_dialogue_templates / event_narratives / story_fragments / literary_phrases / combat_narratives / death_narratives / quest_narratives / style_rules；triggered_fragments 集合记录已触发碎片防重复

### 3. 任务链与奖励梯度
- 8任务构成从新手到史诗的任务梯度：
  - 新手期：铁矿石收集（50金）→ 失踪的儿子（100金）——北村日常委托
  - 成长期：强盗威胁（200金+经验）→ 山贼清剿（500金+公会声望）——区域治安悬赏
  - 中后期：龙鳞收集（符文石+附魔武器）→ 净化教堂（圣光护符+教团声望）——阵营级委托
  - 史诗级：秘银矿石（秘银剑+锻造经验）→ 失踪的公主（贵族头衔+领地+5000金）——王国级任务
- 奖励曲线：金币 50→100→200→500→5000 五档；声望类奖励（公会/教团声望+50~100）替代金币；装备类奖励（铁匕首→疗伤草→秘银剑→符文石→附魔武器→圣光护符）随难度升级
- 任务链联动：奖励贯通 M05 物品系统（铁匕首/疗伤草/秘银剑/符文石）、M04 战斗系统（经验+100）、M03 技能系统（锻造经验+50）
- 任务状态机：accept 触发 → progress 轮询（含进度占位符 {remaining}）→ complete 交付结算

### 5. 阵营关系（faction_relations）
- 关系类型5档：war（战争100）> hostile（敌对80-90）> tense（紧张30-40）> neutral（中立50）> friendly（友好60-70），各含 strength
- 关键阵营关系：
  - 魔王军 vs 光明教团：**war 100**（全面战争）
  - 魔王军 vs 七旧神教会（傲慢/贪婪/色欲/嫉妒/暴食/愤怒/懒惰）：全部 **hostile 80**
  - 光明教团 vs 愤怒教会：hostile 90；vs 傲慢教会：tense 40；vs 魔法学院：neutral 50
  - 冒险者公会 vs 盗贼公会：tense 30；商人行会 vs 冒险者公会：friendly 60
  - 商人行会 vs 盗贼公会：hostile 70
  - 贪婪教会 vs 暴食圣殿：friendly 70；色欲教会 vs 嫉妒教会：friendly 60
  - 傲慢教会 vs 贪婪教会：neutral 50；嫉妒教会 vs 懒惰修道会：neutral 50
  - 熊氏帮派 vs 狼帮：hostile 80
- 阵营关系驱动：区域安全度、NPC立场、任务倾向、声望增减、帮派冲突（@M04遭遇表联动）

### 7. 生成示例
```
场景：冒险者（战士Lv2）在北村接到任务
任务：铁矿石收集（giver=老汤姆，target=收集10块铁矿石）

stage流转：accept → progress（「铁矿石还差{remaining}块」占位符实时填充）→ complete

奖励联动：50金币入M05商店经济；铁匕首入M05武器池（1d4）；锻造经验+50入M03技能
关系变化：完成后老汤姆favor/trust提升 → @M12对话解锁新话题
后续链：铁矿石收集完成 → 可解锁秘银矿石任务（汤姆信任门槛）
```
