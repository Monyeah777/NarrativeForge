### 模块正文 M04：战斗系统

#### 1. 战斗结算流程
```
战斗开始 → 判定先攻（敏捷+环境） → 每回合：行动（攻击/技能/防御/移动/道具）
→ 命中判定（基础值+属性修正+地形修正+姿态修正） → 部位判定（按攻击类型分布）
→ 伤害结算（伤害×部位倍数×地形/姿态×连击奖励×破防/元素反应） → 状态结算 → 士气更新 → 战斗结束
```
- 命中公式：`命中率 = 基础命中 + 敏捷修正 + 地形修正(命中) + 姿态修正(命中) + 随机波动`
- 伤害公式：`最终伤害 = 技能/武器伤害 × 部位伤害倍数 × 地形伤害修正 × 姿态攻击修正 × 连击倍数 × (破防? 2.0 : 1.0)`
- 行动规则数据源：[EXT-资产]action_rules（行29065-30034，25+行为结算规则，含 move_basic / talk_basic / attack_weak_enemy 等，每条含 base_difficulty 与成败效果）

#### 10. 遭遇表机制
- 按地形分区（平原/草原/森林/山地/沼泽/沙漠/雪原/城镇/室内/水下…），每项含：名称 / 描述 / 敌人列表或事件类型 / 权重 / 等级范围 / 区域限制
- 遭遇类型：战斗（enemies）、事件（event，如商人车队/游牧帐篷/野马群）、战利品（loot，如废弃马车）、任务（quest，如迷路的旅行者）
- 示例：平原——野狼群(weight20,Lv1-5) / 流浪强盗(weight15,Lv2-6) / 商人车队(weight10,事件) / 废弃马车(weight12,战利品) / 巨型野猪(weight10,Lv3-8)；草原——鬣狗群(weight20,Lv2-5) / 兽人斥候(weight15,Lv3-8,南兽人之国/东境)
> 数据源：[EXT-资产]encounter_tables（行25382-26150）、monster_spawn_tables

#### 11. 生成示例
```
场景：森林遭遇战（森林地形：命中0.9/闪避1.2/潜行难度0.7）
敌人：野狼（小型：头部1.1/闪避1.2）
玩家：战士Lv3，进攻姿态（攻击1.2/防御0.8）
行动：近战挥砍 → 命中判定成功 → 部位判定（近战表：躯干0.45）命中躯干
伤害：武器15 × 躯干1.0 × 森林1.0 × 进攻1.2 = 18
状态判定：躯干流血20%未触发 → 连击+1 → 士气影响：敌方血量下降，敌方士气低落（攻击0.8/逃跑0.2）
破防尝试：重击判定30%失败，普通破防10%失败 → 未破防
```
