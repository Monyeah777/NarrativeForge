#### 19.1.1 遗传参数总表

| 参数 | 值 | 说明 |
|------|-----|------|

| trait_inheritance_chance | 0.5 | 父母特征单条继承概率 |
| max_traits_per_child | 5 | 单后代最多特征数 |
| recessive_trait_chance | 0.25 | 隐性特征表达概率 |

### M19.2 遗传特征继承机制

**数据源**：`/tmp/extract_test.txt` 行8480-8505（_can_impregnate/_handle_pregnancy/_inherit_trait/_handle_whip）、行8680-8702（give_birth/_create_child）、行8402（mutation_table）

#### 19.2.1 怀孕判定与分娩流程

（一）怀孕判定（_can_impregnate）

| 项目 | 值 | 说明 |
|------|-----|------|
| 触发行为 | sex（混沌行为） | Elona风格任意种族组合皆可判定 |
| 判定概率 | 0.1 | 每次性行为独立判定 |
| 种族限制 | 无硬性限制 | 杂交兼容性矩阵（19.1.3）另行加权 |

（二）怀孕处理（_handle_pregnancy）

- **玩家为女性**：设置 `pregnancy_timer = 30`（天），30天后触发分娩。
- **目标为女性**：在目标NPC数据中标记怀孕状态（@M02 NPC系统）。
- **孕期状态字段**：`pregnancy_timer`（分娩倒计时天数）、怀孕标记。

（三）分娩生成后代（give_birth）

- **触发条件**：`pregnancy_timer` 归零。
- **流程**：生成后代实例 → 添加至 `children` 列表 → 写入NPC谱系（@M02）。
- **后代继承**：按遗传规则从父母双方特征池继承特征。

#### 19.2.2 后代特征生成（_create_child）

（一）特征混合规则

| 规则 | 概率/系数 | 说明 |
|------|-----------|------|
| 继承父亲特征 | 0.5 | 从父亲特征池随机取一条 |
| 继承母亲特征 | 0.5 | 从母亲特征池随机取一条 |
| 特征突变 | 0.05 | 从 mutation_table 随机取突变特征 |
| 后代特征上限 | 5 | max_traits_per_child 上限约束 |

（二）特征继承（_inherit_trait）

- **逻辑**：从玩家与目标双方特征池各随机取一个特征。
- **继承概率**：`trait_inheritance_chance = 0.5`。
- **隐性特征**：`recessive_trait_chance = 0.25` 概率表达。
- **显性特征**：`dominant_trait_boost = 1.2` 强化系数。
- **近亲惩罚**：`inbreeding_penalty = 0.1` 降低后代继承质量。

（三）突变表（mutation_table）

- **位置**：数据源行8402。
- **突变来源**：从 `mutation_table` 随机抽取突变特征（如额外肢体、异色瞳等）。
- **触发概率**：`mutation_rate = 0.05`。

#### 19.2.3 特殊繁衍行为（_handle_whip）

- 鞭打行为（_handle_whip）中额外判定：`can_lay_eggs`（产蛋能力）。
- **产蛋概率**：0.2。
- **产出数量**：1-3 个蛋。
- **蛋的用途**：可孵化后代，与遗传规则联动。

**与 @M18 混沌系统联动**：sex 行为触发怀孕判定 → 30天后分娩 → 后代特征继承（详见 M18.3 混沌引擎逻辑）。
### M19.3 死亡继承联动

**数据源**：`/tmp/extract_test.txt` 行2011-2030（NPCManager._handle_inheritance 遗产继承实现）

#### 19.3.1 继承流程总览

（一）触发时机

- NPC死亡结算后自动触发（@M10 死亡系统）。
- 死亡NPC无继承人时走充公流程。

（二）继承流程5步

| 步骤 | 处理 | 说明 |
|------|------|------|
| 1 | 查找继承人 | 按优先级：配偶→子女→学徒→远亲 |
| 2 | 财产转移 | 死亡NPC物品转移至继承人 inventory |
| 3 | 关系继承 | 原好感度折半转移给继承人 |
| 4 | 职业继承 | 职业与技能等级继承（等级降低） |
| 5 | 无继承人 | 财产充公至势力/国库 |

#### 19.3.2 继承人查找与财产转移

（一）继承人优先级

1. **配偶**：关系最密切，优先继承。
2. **子女**：血缘后代（与19.2后代生成联动）。
3. **学徒**：NPC收徒关系（@M02 NPC系统）。
4. **远亲**：家族谱系远端关联。

（二）财产转移

- **实现**：`inventory.extend` 将死亡NPC物品并入继承人背包。
- **覆盖范围**：金钱、装备、道具、房产凭证。
- **特殊物品**：契约类物品需满足绑定条件方可继承。

#### 19.3.3 关系与职业继承

（一）关系继承

- **好感度**：原好感度 × 0.5（折半）转移给继承人。
- **关系网络**：死亡NPC的社交关系按继承链重定向。
- **声望**：继承人对原势力的声望部分保留。

（二）职业继承

- **技能等级**：继承后技能等级降低（需重新训练）。
- **职业身份**：继承人继承职业称号与职责（如铁匠铺继承）。
- **家族传承**：世代相传的职业保留家族加成。

（三）无继承人处置

- **财产充公**：转移至所在地势力/城镇国库（@M15 帮派与势力）。
- **遗产购买**：玩家可花费金钱购买充公遗产。
- **谱系终结**：该NPC血统分支终结，遗传链断裂。

**与 @M10 死亡系统联动**：死亡结算 → 继承判定 → 遗产/关系/职业转移（详见 M10 相关章节）。
