### M11.1 魔法五层理论

文字即咒语。艾诺萨的魔法并非吟唱冗长的咒文，而是以「元素词根 + 形态词根 + 效果词根」的短句吟诵而成。所有施法者依循五层进阶之路（@M01 智力/感知属性），每一层开启新的法术槽位与核心技能：

| 层级 | 名称 | 需求（智力/感知） | 元素熟练度门槛 | 法术槽位 | 解锁核心技能 |
|---|---|---|---|---|---|
| L1 | 基础感知 | 智力10 感知10 | — | cantrip×999 / layer1×3 | 魔力感知、基础冥想、元素亲和·初级 |
| L2 | 自然共鸣 | 智力12 感知12 | 熟练度总和≥50，至少两种元素≥20 | layer1×4 / layer2×2 | 元素召唤·初级、自然祝福、元素护盾 |
| L3 | 元素掌控 | 智力14 感知14 | 熟练度总和≥150，至少三种元素≥30 | layer1×4 / layer2×3 / layer3×1 | 火球术、冰箭术、闪电术、土墙术、风刃术 |
| L4 | 融合汇聚 | 智力16 感知16 | 熟练度总和≥250，至少四种元素≥40 | layer1×5 / layer2×4 / layer3×2 / layer4×1 | 熔岩爆裂、冰风暴、雷暴、元素共鸣、复合护盾 |
| L5 | 性质附魔 | 智力18 感知18 | 熟练度总和≥400，所有元素≥50 | layer1×6 / layer2×5 / layer3×3 / layer4×2 / layer5×1 | 永燃火炬、寒冰武器、雷鸣之锤、元素化身、魔法结界 |

- 提升规则：施放对应元素法术提升该元素熟练度；熟练度总和达标后自动晋升下一层（@M01 升级流程同步结算）。
- 槽位规则：layerN 槽位数量表示可同时「铭刻」的该层法术数；超出部分进入待机序列，战斗中可切换（冷却1回合）。

### M11.5 文字即咒语：咒语生成规则

咒语 = **元素词根（E）+ 形态词根（F）+ 效果词根（X）**，按「E-F-X」顺序吟诵即构成一段可施放的咒语：

- 解析规则：解析引擎按词根库匹配三个成分（@M03 技能习得机制共用解析器）；缺省效果词根时默认「伤」（伤害）。
- 法力消耗：法力 = 元素词根法力 + 形态词根法力 + 效果词根法力（效果倍率向上取整）。
- 强度公式：基础强度 = 元素熟练度 × 效果倍率 × 克制系数（@M11.2）；形态词根修正范围与目标数。
- 组合进阶：同回合施放两种元素咒语 → 触发二元素组合（见 M11.6）；三种元素 → 触发三元素组合（动态生成）。
- 失败判定：智力/感知低于对应层级需求时，咒语有（需求差×10）%概率失败（魔力照常消耗）。

**咒语示例：**

| 咒语 | 词根组合 | 效果 |
|---|---|---|
| 「Ign Sphere Damage」炎·球·伤 | 火+球+伤害 | 火球术（L3，3d6+5火焰，20%点燃） |
| 「Aqu Projectile Freeze」渊·箭·冻 | 水+箭+冻结 | 冰封箭（3d8冰霜，冻结1秒） |
| 「Ter Wall Protect」岩·墙·护 | 土+墙+防护 | 石壁术（护甲+5，持续30秒） |
| 「Lux Rain Heal」辉·雨·疗 | 光+雨+治疗 | 光雨愈场（范围4治疗，倍率1.2） |
| 「Umbr Claw Curse」影·爪·咒 | 暗+爪+诅咒 | 影爪诅咒（降低目标5%全属性） |
