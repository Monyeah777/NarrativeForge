## M10.死亡与重生

### 1. 死亡结算流程
> 死亡是旅途的终点，也是新生的起点。每位玩家死亡时按「死因判定 → 死亡描述 → 祝福结算 → 重生」四步流程结算。

**四步结算流程**

| 步骤 | 阶段 | 说明 | 数据源 |
|------|------|------|--------|
| 1 | 死因判定 | 依据致死来源确定死因分类（39种），优先级见下 | death_descriptions |
| 2 | 死亡描述 | 从对应死因的4条模板中随机选取1条，填充{player_name}占位符 | death_descriptions |
| 3 | 祝福结算 | 按死因从blessing_pool对应祝福池抽取祝福；动态生成器可产出组合祝福 | blessing_pool / 动态生成器 |
| 4 | 重生 | 玩家在绑定重生点复活，承受死亡惩罚后继承祝福 | 重生机制 |

**死因判定优先级**（由高到低）：
1. 即死效果：instant_death（即死法术/斩首/即死陷阱）
2. 特殊维度：void（虚空）/ dream（梦境）/ time_accel（时间加速）/ celestial（天灾）
3. 特定生物：dragon（龙族）/ demon（恶魔）/ undead（亡灵）/ beast（野兽）/ doppelganger（镜像分身）
4. 元素异常：burned（烧死）/ frozen（冻死）/ drowned（溺死）/ shock（电死）/ petrify（石化）/ poisoned（中毒）/ cursed（诅咒）
5. 物理伤害：sharp（利器）/ blunt（钝器）/ fall（摔落）/ bleed（失血）/ exhaustion（力竭）
6. 其他：combat（战斗）/ magic_backlash（魔法反噬）/ holy（圣光）/ dark（黑暗）/ time（时空扭曲）/ fragment（原罪碎片）/ trap（陷阱）/ scroll（卷轴意外）/ summon（召唤物）/ cursed_item（诅咒物品）/ old_age（衰老）/ self_destruct（自爆）/ plant（植物）/ mental（精神攻击）/ generic（通用）

### 4. 动态死亡祝福生成器
> 数据源：动态死亡祝福生成器（行19497-20119）。在固定祝福池之外，系统可按死因动态生成组合祝福（前缀BLESS_），生成规则如下。

**生成规则**：
1. 输入死因分类（39种之一）与死亡情境（战斗 / 环境 / 魔法 / 特殊）
2. 从死因主祝福池抽取1条基础祝福（如BLESS_TIMEACCEL时间加速类）
3. 按情境附加1条次级效果：战斗→攻击类、环境→抗性类、魔法→法力类、特殊→保命类
4. 组合祝福继承主祝福的叠加层数（每层+X，最多5层）
5. 专属祝福（GODS_FAVOR等6个）仅在特定成就 / 条件达成时替代普通祝福

**动态生成示例**：
- 死因=被龙族杀死 + 情境=魔法 → 龙血沸腾（主）＋魔力回流（次）→ 组合祝福「龙血沸腾·魔」
- 死因=时间加速 + 情境=特殊 → 时光倒流（主）＋命不该绝（次）→ 组合祝福「时光逆流」
- 死因=自爆 + 情境=战斗 → 同归于尽（主）＋不屈意志（次）→ 组合祝福「决死之志」

### 5. NPC死亡触发（npc_death_triggers）
> 数据源：npc_death_triggers（行21844-21876）。NPC意外死亡概率模型：
> 意外死亡概率 = base_accidental × 职业倍率 × 年龄倍率 ×（1 + Σ环境系数）

**基础参数**：

| 参数 | 值 | 说明 |
|------|-----|------|
| base_accidental | 0.0002 | 意外死亡基础概率（每日） |
| danger_level_factor | 0.2 | 危险区域额外系数 |
| war_factor | 2.0 | 战争期间系数 |
| disease_factor | 1.3 | 瘟疫期间系数 |

**职业倍率 occupation_mult**：

| 职业 | 倍率 | 职业 | 倍率 |
|------|------|------|------|
| 战士 | 1.5 | 盗贼 | 1.4 |
| 游侠 | 1.3 | 吟游诗人 | 1.0 |
| 法师 | 1.2 | 萨满 | 1.1 |
| 牧师 | 1.1 | 魅惑师 | 1.0 |
| 铁匠 | 0.8 | 商人 | 0.7 |
| 农夫 | 0.9 | 学者 | 0.6 |
| 冒险者 | 1.8 | | |

**年龄倍率 age_factor**：

| 年龄段 | 倍率 | 年龄段 | 倍率 |
|--------|------|--------|------|
| 儿童 | 0.3 | 中年 | 1.0 |
| 少年 | 0.5 | 老年 | 1.5 |
| 青年 | 0.8 | 耄耋 | 2.0 |

**意外池 accident_pool**（8种意外原因）：意外 / 疾病 / 野兽 / 仇杀 / 战争 / 衰老 / 诅咒 / 魔法反噬

**NPC死亡结算**：
1. 每日结算：probability = base × occ_mult × age_factor ×（1 + Σ环境系数）
2. 命中后从accident_pool随机抽取意外原因
3. NPC死亡后触发连锁反应：关系网络更新（@M06）、帮派/阵营变动、任务链调整（@M06）

### 6. 重生机制
> 重生是死亡惩罚与祝福继承的落点。玩家死亡后在绑定重生点复活。

**重生规则**：

| 项目 | 规则 |
|------|------|
| 重生点 | 玩家绑定的城镇旅店/神殿/复活点（@M07区域），未绑定则随机最近城镇 |
| 死亡惩罚 | 损失当前等级经验的10% + 随身金币的5%（不损失装备与技能） |
| 祝福继承 | 重生后保留本次死亡的祝福效果（永久，可叠加至5层） |
| 特殊重生 | 转生（REINCARNATION）保留全部属性；双生灵魂20%概率以分身替代死亡 |
| 死亡冷却 | 30分钟内重复死亡，死亡惩罚翻倍（最多3倍） |
| 强制事件 | 关键剧情死亡（被原罪碎片侵蚀等）触发剧情事件而非普通重生 |

**重生后祝福叠加规则**：每次死亡获得的祝福进入「祝福栏」，同类祝福叠加层数（每层+X，最多5层）；不同类祝福共存，上限10条，超出时玩家选择替换。

### 7. 生成示例
```
场景：玩家在龙脊山脉被巨龙吐息击杀（dragon死因），当前等级15级
1. 死因判定：致死来源为龙族 → dragon
2. 死亡描述：从dragon的4条模板随机 → 「被巨龙吐息烧成灰烬」（填充{player_name}）
3. 祝福结算：从dragon祝福池抽取 → 龙血沸腾（生命+15%，龙类伤害+15%）
4. 动态生成器：情境=战斗（被吐息）→ 附加攻击类次级效果 → 组合祝福「龙血沸腾·攻」
5. 重生：绑定重生点=龙脊镇旅店 → 损失经验10%（1500→1350）＋金币5%（1000→950）→ 祝福入栏
6. 若30分钟内再次死亡 → 死亡惩罚翻倍（经验20%）
7. NPC连锁：若同行NPC冒险者死亡判定（0.0002×1.8×1.0）命中 → 触发「同伴之死」事件（@M06任务链）
```
