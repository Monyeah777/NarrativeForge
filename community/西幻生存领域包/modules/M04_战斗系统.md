# 模块 M04 · 战斗系统

> 类别：生存｜来源：西幻｜挂载点：P50 交互执行（active）｜依赖：M02、M03、M07、M08｜发布：`combat_result`

## 1. 职责

**回合制战斗结算中枢**：伤害计算、命中/部位、连击、姿态、破防、元素反应、士气与遭遇（对应骨架 M04）。

## 2. 战斗结算流程

```yaml
combat_resolve:
  1. 先攻排序（dex + 环境修正）
  2. 攻击判定: 命中 = 攻方命中修正 - 守方闪避 + 地形/姿态修正 + 骰值
  3. 命中 → 部位抽取（见下）→ 伤害 = 攻击力 × 技能倍率 - 防御
  4. 破防判定 → 连击奖励判定
  5. 元素反应结算（若带元素）
  6. 士气/体型修正（若适用）
  7. 双方结算 → 发布 combat_result
```

## 3. 关键规则表（数据在资产库西幻包）

```yaml
terrain_mods:   11 地形 × 5 战斗属性修正表（林地弓手+、沼泽移动-）
body_parts:     部位命中分布与部位效果（头/躯干/四肢…）
postures:       5 姿态（攻/守/速/狂/隐），姿态克制关系
break_defense:  5 类破防规则（盾破/甲破/架势崩/元素侵/要害曝）
element_reaction: 9 元素反应组合（火+风=扩散、水+雷=导电…）
destructibles:  6 种可破坏物体（门/墙/桥/柱/桶/机关）
morale_size:    士气低落 → 全属性-；体型差 → 击退/压制修正
encounter_table: 遭遇表（区域×时间→怪物池，M07/M08 输入）
```

## 4. 连击奖励系统

```yaml
combo:
  条件: 连续命中且未中断（守方未成功反击/闪避）
  奖励: 连击数越高伤害倍率递增，最高 ×2.0；被打断清零
```

## 5. 事件契约

```yaml
subscribe:
  spell_cast:      # M11 法术入战斗结算（元素+伤害）
  quest_state:     # M06 任务目标（击败X）监听
  travel_event:    # M07 旅行遭遇触发战斗
  weather_state:   # M08 天气修正（雨→火- 雷+）
  minute_tick:     # P03 分钟制遭遇
publish: combat_result
  payload: {winner, participants, damage_log, loot_hint, tick}
  subscribers: [生存:M10, M03, M06]
```
