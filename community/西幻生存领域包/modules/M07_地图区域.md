# 模块 M07 · 地图区域
> 类别：世界｜来源：西幻｜挂载点：P60 长期演变（active）｜依赖：M00、M08｜被依赖：M04、M06、M09｜发布：`travel_event`

## 1. 职责
管理世界**区域拓扑、旅行规则与地点刷新**：定义 11 大区域（regions）、60+ 地点实例（locations）、旅行耗时与遭遇判定、地点描述随季节/天气/时间刷新。对应西幻骨架 M07。为 M04 战斗（地形修正）、M06 任务（地点目标挂点）、M09 经济（region_mult 区域价格系数）提供地理上下文。

## 2. 区域与地点结构
```yaml
region:
  id: 北境 | 中土 | 南境 # …共 11 区域
  terrain: 联动 M04 地形修正表
  season_mult: {春, 夏, 秋, 冬}   # 供 M08/M09 引用
  economy_mult: # 供 M09 定价
  control: # 阵营/帮派控制方，联动 M14/M15
location:
  id: 北村
  region: 北境
  type: 城镇 | 村落 | 野外 | 地牢 | 遗迹
  npc_refs: []   # 常驻 NPC，联动 M13
  quest_refs: [] # 任务挂点，联动 M06
  refresh: 描述刷新规则（受 M08 天气/季节驱动）
```
- 11 区域全表、60+ 地点与 travel_rules 数值 → 本包 assets/（随附，经 asset_get 寻址）（本模块仅保留结构）。
- 旅行规则：`耗时 = f(距离, 负重, 天气修正)`；遭遇率按区域危险度与 M04 威胁表。

## 3. 事件契约
```yaml
subscribe:
  weather_state: # M08 → 天气影响旅行与区域描述刷新
publish:
  travel_event:
    payload: {from, to, route, duration, encounters[], weather_mod}
    subscribers: [M04, M06, M09]
```

## 4. 结算流程
1. 玩家/队伍发起旅行（经 M50 主循环调度）。
2. 读取区域拓扑与 travel_rules 计算耗时与遭遇。
3. 消耗时间（告知 通用:M10）并发布 travel_event。
4. M04 用目的地地形准备战斗修正；M06 检查任务地点；M09 刷新区域市价。

## 5. 违例与边界
- M07 只提供地理数据与旅行结算，**不创建 NPC 个体**（M13）、**不生成任务**（M06）。
- 区域静态属性改动须走资产库，禁止模块内硬编码新区域。
- 旅行中遭遇战斗只发布事件，不自行结算（裁决归 M04）。
