# 模块 M18 · 混沌事件
> 类别：事件｜来源：西幻｜挂载点：P30 事件生产（active）｜依赖：M15、M16｜被依赖：M06、事件:M22、生存:M10、M65｜发布：`chaos_event`

## 1. 职责
管理**混沌规则、随机事件与动态世界扰动**：在一致性约束内生成世界级扰动提议（自然/社会/超自然/原罪碎片异动），经 FreedomManager 引擎校验后广播。对应西幻骨架 M18（chaos_rules / chaos 行为规则 / FreedomManager 混沌引擎）。是世界"意外"的生产者——但**不得破坏已建立的因果链**。

## 2. 混沌规则
```yaml
chaos_rules:
  允许: 在既成因果之外添加扰动
  禁止: 推翻已发布叙事结论 / 无铺垫空降重大事件 / 破坏角色已立行为
chaos_event:
  type: 自然灾害 | 社会动荡 | 超自然异象 | 原罪碎片异动
  magnitude: 轻微 | 显著 | 重大
  region: # 目标区域（M07）
  targets: []  # 影响对象（据点 M16 / 帮派 M15 / NPC M13）
freedom_manager:
  生成: 随机种子（由 M50 统一提供）
  校验: 与已发布叙事冲突 → 降级或拒绝
  裁剪: 事件素材按 M23 视角域供给玩家
```
- 混沌行为规则全表（可触发/不可触发清单） → 本包 assets/（随附，经 asset_get 寻址）。

## 3. 事件契约
```yaml
subscribe:
  faction_event: # M15 → 帮派火并/政变可升级为混沌扰动
publish:
  chaos_event:
    payload: {type, magnitude, region, targets[], constraints, seed}
    subscribers: [M06, 事件:M22, 生存:M10, M65]
```

## 4. 结算流程
1. 周期性掷混沌判定（或由 M15 faction_event 诱发）。
2. FreedomManager 生成扰动提议并做一致性校验。
3. 通过 → 发布 chaos_event；拒绝 → 降级或静默丢弃。
4. 订阅方响应：M06 改写任务、事件:M22 编排叙事、生存:M10 结算伤亡、M65 沉淀遗憾素材。

## 5. 违例与边界
- M18 只生成**扰动提议**：叙事成型（措辞/因果/顺序）归事件:M22；死亡后果归生存:M10。
- 混沌不得直接抹除玩家既有成就或关系数值（需经事件:M22 与 M50 回卷机制）。
- 随机性必须来自 M50 种子，禁止模块内另起随机源（保证可复现）。
