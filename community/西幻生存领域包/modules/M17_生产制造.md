# 模块 M17 · 生产制造

> 类别：生存｜来源：西幻｜挂载点：P50 交互执行（active）｜依赖：M00、M09｜发布：`production_output`

```yaml
machine_contract:
  schema: "1"
  id: M17
  name: 生产制造
  category: 生存
  layer: P50
  inputs: []
  outputs: []
  events:
    publish: [production_output]
    subscribe: [market_event]
  interfaces: []
```

## 1. 职责

管理**采集、制造与产出**：以 ProductionRecipe 配方表驱动食物/材料/武器/炼金/锻造等生产链路，产出进入经济系统（M09）（对应骨架 M17）。

## 2. 配方数据结构（ProductionRecipe）

```yaml
ProductionRecipe:
  id: 唯一配方号
  category: [食物, 材料, 武器, 防具, 药水, 炼金, 锻造, 建筑]
  inputs: {材料A: 数量, 材料B: 数量}
  output: {物品, 数量}
  requirements: {技能等级, 工具, 据点设施(M16), 配方书}
  duration: 生产耗时（分钟制 tick）
```

## 3. 配方库（节选，完整见资产库西幻包）

```yaml
food_recipes:    5+（面包/炖肉/药膳…）      → 恢复 vitals（M01 消费）
material_recipes: 8+（皮革/铁锭/魔晶碎…）   → 中间材料
weapon_recipes:  6+（铁剑/长弓/法杖…）      → M04 战斗装备
special:         炼金/附魔配方（联动 M11 元素/词根）
```

## 4. 生产流程

```yaml
produce(player, recipe_id):
  1. 校验材料/工具/技能/设施（M16 据点设施加成）
  2. 扣除材料 → 进入生产队列（duration 倒计时，M10 分钟制结算）
  3. 完成 → 产出物品（进背包/仓库）→ 发布 production_output
  4. 技能熟练度+（M03）；品质波动（成功/大成功/失败）
```

## 5. 经济联动

```yaml
subscribe: [market_event]      # M09 市场价格波动 → 调整生产成本/售价
publish: production_output
  payload: {recipe_id, item, qty, quality, cost, tick}
  subscribers: [M09, 事件:M22]
产出去向: 自用 / 商店出售（M09）/ 委托交付（M06 任务）/ 据点建设（M16）
```

## 6. 违例与边界

- 无配方条目禁止凭空产出（防刷）；配方的材料/产出比由 M09 经济模型校准。
- 生产行为属玩家可控操作，NPC 生产走 M13 日程（不占用玩家队列）。
