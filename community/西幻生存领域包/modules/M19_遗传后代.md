# 模块 M19 · 遗传后代

> 类别：生存｜来源：西幻｜挂载点：P20 角色状态（available）/ P60 长期演变（available）｜依赖：M00｜发布：无

## 1. 职责

管理角色**婚恋生子与后代遗传**：后代由双亲基因型（种族/属性/天赋）合成，成为可继承的可控/伙伴角色（对应骨架 M19）。本模块是"跨代际叙事"（写作 DNA2 物件跨代）的系统支撑。

## 2. 后代生成

```yaml
offspring_gen(parents):
  1. 合法性检查（关系状态恋爱/婚姻判定——经事件桥读取 NPCState 关系字段，不直引校园模块；+ 世界规则 M20）
  2. 种族判定: 父母同族 → 同族；异族 → 按 M02 杂交规则（主属性取均值）
  3. 属性: 父母属性均值 + 随机浮动（±区间）
  4. 天赋: 一方主天赋线 + 小概率觉醒新天赋（血统变异）
  5. 初始关系: 与父母双方继承 50% 关系深度基线
```

## 3. 成长与继承

```yaml
growth:
  年龄推进: 随 tick_day 成长（幼年→少年→成年各阶段解锁能力）
  培养: 父母可投入资源（M09 货币/ M17 生产）影响后代成长方向
继承:
  后代继承家族物件/技能传承（供写作 DNA2 物件意象取用）
  父母死亡（生存:M10）→ 后代可继承遗物与未竟之志（遗憾线延伸经事件桥转校园情感包 ghost_event 通道）
```

## 4. 与阵营/帮派联动

```yaml
被依赖: [M14, M16]
  阵营继承: 后代出生自带父母阵营声望基线（M14）
  据点继承: 后代可成为据点（M16）继承人/管理者
```

## 5. 事件契约

```yaml
subscribe: [tick_day]     # 后代年龄/成长结算
```

## 6. 违例与边界

- 后代生成必须满足关系合法状态（恋爱/婚姻，经事件桥判定），禁止无关系强生（防剧情崩坏）。
- 本模块只产出基因型与成长线，性格/命运由 M13/事件:M22 后续塑造。
