# 模块 M11 · 文字魔法

> 类别：生存｜来源：西幻｜挂载点：P50 交互执行（active）｜依赖：M20｜发布：`spell_cast`

## 1. 职责

实现**文字即咒语**的独特魔法体系（对应骨架 M11）：魔法不靠咒语念诵，而靠文字书写/言灵本身驱动。

## 2. 魔法五层理论

```yaml
magic_layers:
  L1 文字层:  词根/字符是魔法最小单位
  L2 语义层:  词根组合产生语义（咒语结构）
  L3 元素层:  语义映射到七元素（属性赋予）
  L4 规则层:  世界法则约束（代价/反噬/上限）
  L5 叙事层:  咒语效果进入叙事（M80 呈现）
```

## 3. 七元素体系

```yaml
elements: [火, 水, 风, 土, 雷, 光, 暗]
  元素相性: 二元素组合表 22 条（火+风=扩散…详见资产库）
  元素克制: 光↔暗 互克；水克火、火克风…（完整环在资产库）
```

## 4. 法术库与词根库

```yaml
spell_library:  预置法术（按七元素+学派分类，数据在资产库）
root_library:   词根库（每元素一组词根：如 火=炎/灼/焚）
生成规则:
  咒语 = 词根序列（元素词根 + 效果词根 + 范围/目标词根）
  二元素组合 22 条表驱动复合效果（M24 组合注册）
```

## 5. 文字即咒语：书写规则

```yaml
cast_by_word:
  载体: 吟唱（口述）/ 铭文（书写）/ 契约（血书）/ 咒物（刻印）
  代价: 每次施法消耗（法力/寿命/记忆/声音等，依 L4 规则）
  反噬: 元素冲突/语义歧义 → 施法事故（混沌事件候选，M18）
  失效: 在禁魔区/被沉默（M08 天气/ M07 区域规则）→ spell_cast 返回 blocked
```

## 6. 事件契约

```yaml
publish: spell_cast
  payload: {caster, spell, elements, target, effect_summary, tick}
  subscribers: [M04, M03]   # 战斗结算 / 技能熟练度
```

## 7. 违例与边界

- 新法术须先经 M24 组合注册（词根+组合表）方可施放，禁止自由发挥造法。
- 咒语文本生成受写作 DNA 约束：短、有节奏、具象（与白描交替）。
