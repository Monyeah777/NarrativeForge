# 模块 M01 · 职业成长

> 类别：生存｜来源：西幻｜挂载点：P20 角色状态（active）｜依赖：M00、M02、M20｜发布：`level_up`

## 1. 职责

管理角色**基础属性、等级经验与生存状态**：从角色创建到职业成长的主属性通道。本模块是西幻流的数值地基（对应骨架 M01，18 职业完整数据见资产库）。

## 2. 七项基础属性（默认 10）

```yaml
attributes: {str, dex, con, int, wis, cha}
  str 力量 / dex 敏捷 / con 体质 / int 智力 / wis 感知 / cha 魅力 / luc 幸运(扩展)
属性作用: 战斗修正（M04）、技能判定（M03）、社交判定（M13）的输入
```

## 3. 等级与经验

```yaml
exp_curve:
  exp_next = 10 × 1.5^(level-1)     # 升到下一级所需经验
  level_up: exp ≥ exp_next → level+1，属性点+，触发 level_up 事件
  经验来源: 战斗（M04 combat_result）/ 任务（M06）/ 生产（M17）/ 事件（M18）
```

## 4. 生存状态管理（vitals）

```yaml
vitals: {health, hunger, thirst, fatigue, temperature, insanity}
  结算节拍: tick_day（每日）+ P03 分钟制（每 10 分钟刻）
  扣减:   活动消耗 hunger/thirst/fatigue；极端环境改 temperature；精神创伤改 insanity
  阈值:
    health=0 → 交生存:M10 死亡判定
    hunger/thirst/fatigue 归零 → health 持续扣减
    insanity ≥ 80 → 幻觉事件（交事件:M22 编剧）
  恢复:   进食/饮水/睡眠/治疗（M17 产出、M12 服务消费）
```

## 5. 职业成长表（18 职业，节选）

| 职业系 | 主属性 | 典型职业 | 特性 |
| --- | --- | --- | --- |
| 战士系 | str/con | 剑士、狂战士 | 近战修正+ |
| 游侠系 | dex | 弓手、刺客 | 敏捷判定+ |
| 法系 | int/wis | 法师、祭司 | 施法修正+ |
| 生活系 | 混合 | 铁匠、炼金、农夫、商人 | 生产/贸易修正+ |
| 特殊系 | cha | 吟游诗人、贵族 | 社交修正+ |

完整 18 职业成长表（含每级属性成长/技能解锁/转职条件）存放于 本包 assets/（随附，经 asset_get 寻址）。

## 6. 事件契约

```yaml
subscribe: [tick_day, combat_result, minute_tick]  # 结算经验与生存消耗
publish: level_up
  payload: {job, from_lv, to_lv, gained_attrs, tick}
  subscribers: [M03, M13]
```

## 7. 违例与边界

- 属性/等级变更唯一入口为本模块接口，其他模块不得直写 PlayerState.attributes。
- 生存状态归零但主角为"关键剧情存活者"时，由事件:M22 编剧接管（豁免一次需显式标记）。
