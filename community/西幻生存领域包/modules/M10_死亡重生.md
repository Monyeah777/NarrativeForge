# 模块 生存:M10 · 死亡重生

> 类别：生存｜来源：西幻｜挂载点：P40 行为决策（available）/ 结算在 M50 第 13 步｜依赖：M04｜发布：`death_trigger`

## 1. 职责

处理**死亡结算与重生**（对应骨架 M10）。本世界观的核心设定：**死亡不结束游戏**，进入重生流程（死亡祝福/遗物继承）。

## 2. 死亡结算流程

```yaml
death_resolve(combat_result):
  1. 确认死亡（health=0 且未被事件:M22 豁免）
  2. 从 death_descriptions 池抽取死亡描述素材（供 M80，遵守写作 DNA7）
  3. 生成死亡祝福（blessing_pool 抽取 or 动态生成器）
  4. 确定遗物继承范围（技能/物品/关系记忆）
  5. 发布 death_trigger → 进入重生流程
```

## 3. 祝福池与动态生成

```yaml
blessing_pool:
  静态池: 预置祝福（复生减损/属性微调/记忆保留）
  动态生成器: 依据死亡方式+种族+职业实时生成专属祝福
  祝福代价: 重生后短期虚弱（全属性- 持续 N tick）
```

## 4. NPC 死亡触发

```yaml
npc_death_triggers:
  重要 NPC 死亡 → death_trigger 广播（跨题材遗憾线经事件桥转校园情感包；事件:M22 编剧线开启）
  一般 NPC 死亡 → 按 M13 死亡与继承规则替换/继承
```

## 5. 重生机制

```yaml
rebirth:
  重生点: 绑定据点（M16）/ 最近安全区 / 特殊信仰点
  损失: 部分未绑定物品与技能经验（详见资产库死亡损失表）
  继承: 种族血脉技能 100%；职业技能按遗物/祝福保留（M03.4）
  叙事衔接: 死亡与重生作为剧情节点可被事件:M22 利用（预言/诅咒/使命）
```

## 6. 事件契约

```yaml
subscribe: [combat_result, quest_state, chaos_event]  # 可致死的结算来源
publish: death_trigger
  payload: {deceased, cause, blessing, lost_items, rebirth_point, tick}
  subscribers: [事件:M22]  # 跨题材遗憾下游（校园情感包）经事件桥登记，非直接模块互引
```

## 7. 违例与边界

- "死亡结束游戏"在本世界观不存在；所有死亡必须走重生（永久死亡线须事件:M22 显式编剧）。
- 死亡结算期间禁止经事件桥接入的关系数值推进类模块继续推进关系数值（防错位）。
