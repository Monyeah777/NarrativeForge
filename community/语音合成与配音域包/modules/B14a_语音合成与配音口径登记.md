> 类别：语音合成与配音｜来源：社区（语音合成与配音域包自带，类内段）｜挂载点：P40 行为决策（active，default）｜依赖：M00、M50｜发布：b14_spec_ready、b14_spec_conflict｜状态：active
> 用途：逐条登记本域 12 个细分口径（定义 / 可机验判据 / 失效模式），校验齐备性与词表边界；越界或缺项即发布口径冲突事件。

## 1. 职责

逐条登记本域 12 个细分口径（定义 / 可机验判据 / 失效模式），校验齐备性与词表边界；越界或缺项即发布口径冲突事件。

域知识结构不写死在模块里：概念前置在资产 `CONCEPT_GRAPH`，口径在资产 `DOMAIN_SPEC`（图 = 内容，口径 = 机制，三正交分离）。

## 2. 协议声明（01 §2 模块协议）

```yaml
Module:
  id: 语音合成与配音:M01
  name: 语音合成与配音口径登记
  layer: P40
  inputs: [M00, M50]
  outputs: [domain_spec, spec_conflict_list]
  events:
    publish: [b14_spec_ready, b14_spec_conflict]
    subscribe: [b14_report_ready, b14_report_conflict]
  core:
    assets: [CONCEPT_GRAPH, DOMAIN_SPEC, STANDARDS_ANCHORS]
    logic:
      读口径: 从 DOMAIN_SPEC 读 12 条细分的定义 / 判据 / 失效模式
      登记: 逐条登记 Spec 条目（id ∈ 条目键表，判据非空，锚为绝对 URL）
      校验: 判据齐备且锚可达性已记档 → 通过；缺项 / 锚非 URL → spec_conflict
      落槽: 写 DomainSpecState{subdivisions, conflicts, tick}
      发布: 全通过 → b14_spec_ready；否则逐条 b14_spec_conflict
```

## 3. 产出面（可机验）

| 产出 | 形态 | 档位 | 说明 |
|---|---|---|---|
| `outputs/DOMAIN_SPEC.json` | 结构化数据 | T3 | 口径表机读投影（与资产双源一致） |
| `outputs/REPORT.json` | 可复算报告 | T4 | 度量族重算（check32 逐字段比对） |
| `outputs/charts/*.vega.json` | 图表规格 | T3 | 由报告确定性生成 |
| `outputs/CONCEPT_DAG.graphml` 等 | 图结构 | T3 | 由概念图确定性派生 |

## 4. 事件联动（机读契约）

```yaml
event: b14_spec_ready
payload: { subdivisions: number, checked: number, tick: number }
description: 口径面齐备（12 条全过判据）
```

```yaml
event: b14_spec_conflict
payload: { field: string, reason: string, blocking: boolean }
description: 口径缺项 / 越词表 / 锚非 URL
```

## 5. 边界与不宣称

- 本模块**不产出模型能力结论**：报告是样例集上的口径值，不是能力评测结论。
- 外部锚只作口径参照，不作质量背书；口径表正文自撰。
- 域包不承担该域的教学职能：包外前置族（B14-00）须装载方自备。
