# 模块 M55 · 匿名情书

> 类别：情感｜来源：校园｜挂载点：P40 行为决策（active）｜依赖：M40、M43｜发布：无（叙事素材交事件:M22）

## 1. 职责

承载校园经典的**匿名情书**事件链：写→投→收→（误）→回。情书的匿名性天然制造认知偏差与误会空间，是 M23 认知边界的经典应用场景。

## 2. 情书事件链

```yaml
love_letter_chain:
  write:    主角选择写信对象与署名方式（实名/匿名/冒名）
  deliver:  投递通道：鞋柜/书桌/信箱（资产 LOCATIONS 30 条中取样）
  receive:  收信人判定：默认目标NPC；可被情敌事件/误放篡改（认知偏差）
  respond:  收信人按 M40 关系深度 + 大五人格决定反应（惊喜/困惑/回避）
  reveal:   匿名揭晓窗口：由事件:M22 安排（直接揭晓/拖长悬念/永不揭晓→M65 遗憾）
```

## 3. 匿名性规则

```yaml
anonymity:
  系统真知: 谁写的、写给谁，系统层完整保留（真相唯一 I5）
  角色认知: 收信人只能推断（依据笔迹/内容/时机等证据），推断错误合法
  冒名风险: 情敌/第三方可冒名投递 → 引发误会事件（须过 M23 后才可呈现）
  揭晓限制: 揭晓前，主角与收信人的"真相对齐"属隐藏域
```

## 4. 事件契约

```yaml
subscribe:
  relationship_change:   # 关系档位变化 → 情书反应基线更新
  confession_event:      # 告白竞争时情书可成为关键证据/信物
  npc_action:            # 冲动行为可能触发"冲动回信"
输出: 情书事件素材写入 EventState.pending_narratives，交事件:M22 编排
```

## 5. 违例与边界

- 情书文本生成受写作 DNA8（对话极简）约束：信件正文短、口语、带潜台词。
- 禁止系统在揭晓窗口前向玩家输出"这是某某写的情书"式直述。
