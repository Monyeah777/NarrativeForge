# 模块 M41 · 恋爱进阶

> 类别：情感｜来源：校园｜挂载点：P40 行为决策（active）｜依赖：M40｜发布：`romance_state_change`

## 1. 职责

在 M40 关系深度的基础上管理**恋爱阶段**的推进与回退：阶段门槛、告白判定、心意确认与恋爱状态机。

## 2. 恋爱阶段状态机

```yaml
romance_stages:
  0 陌生人:     depth < 20     # 无特殊互动
  1 熟识:       depth 20-39    # 普通朋友，日常互动
  2 好感:       depth 40-59    # 特殊关注，暧昧前兆
  3 暧昧:       depth 60-79    # 双向好感信号，可触发告白
  4 恋爱:       depth ≥ 80     # 告白成功/心意确认
  5 特殊分支:   由事件:M22 编剧解锁（暗恋/错过/遗憾等）
推进条件:
  - 阶段提升：depth 达标 且 cognition 达标（双向了解足够）
  - 阶段回退：relationship_change 负向击穿阈值（M40 破坏效应）
```

## 3. 告白判定

```yaml
confession_check(npc):
  1. 双方处于暧昧阶段（depth ≥ 60）
  2. 该 NPC 有告白窗口（由 M43 情敌/剧情事件打开）
  3. 主角在场且无阻碍条件（情敌阻挠/认知边界外信息）
  4. 通过 → 发布 romance_state_change {stage: 4}；失败 → 退回暧昧 + 遗憾种子（交 M65）
```

## 4. 事件契约

```yaml
subscribe:
  relationship_change:   # 深度变化 → 检查是否越阶段阈值
  confession_event:      # M43 情敌告白事件 → 触发主角方回应判定
publish: romance_state_change
  payload: {npc_id, from_stage, to_stage, reason, tick}
  subscribers: [M43, M65]
```

## 5. 违例与边界

- 恋爱状态只影响系统判定；叙事呈现须过 M23 认知边界（对方心意在告白前属于隐藏域）。
- 单 NPC 恋爱线独占：进入恋爱后 M43 情敌系统对该 NPC 降权。
