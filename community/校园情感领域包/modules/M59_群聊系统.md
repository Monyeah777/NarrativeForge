# 模块 M59 · 群聊系统
> 类别：情感｜来源：校园｜挂载点：P50 交互执行（active，社交结算段）｜依赖：M00、M40、事件:M22｜发布：`group_chat_event`

## 1. 职责

承载校园社交的**群聊消息流**（资产 GROUP_CHAT，素材池 GOSSIP_TOPICS）：回合内扫描活跃群组，以 `GOSSIP_TOPICS` 为话题素材生成群消息，写入 `player.social.group_chat`。群聊是课间/夜间低强度社交的背景层：消息可触发事件（`trigger_event` → 事件 pending 队列）、影响氛围与好感（M40）；冷场/无人回应 → 沉淀 ghost 素材（M65）。

## 2. 协议声明（01 §1 模块协议）

```yaml
Module:
  id: M59
  name: 群聊系统
  layer: P50
  inputs: [M00 数据槽, M40 关系深度, GOSSIP_TOPICS 素材池]
  outputs: [player.social.group_chat, events.pending(群聊触发点)]
  events:
    publish: [group_chat_event]       # 群消息就绪/群聊触发点
    subscribe: [quest_state, npc_action, relationship_change]
  core:
    assets: [GROUP_CHAT, GOSSIP_TOPICS]  # I4：仅经 asset_* 五接口访问，禁止直读
    logic:
      scan_group_chats: asset_query(GROUP_CHAT, active) → 每群 asset_roll(素材=GOSSIP_TOPICS) 生成消息 → 入 group_chat；含 trigger_event 的消息入事件 pending；冷场沉淀 ghost 素材
  replaceable: true
```

## 3. 触发时机

P50 层**社交结算段**（与 M57/M58 同段依序执行）：位于任务推进之后、P60 演变之前，由 M50 按注册表顺序调度调用 `scan_group_chats`（见 assets/附_社交系统触发联动.md §12.5）。课间/夜窗口群活跃度更高（校园作息）。

## 4. 核心逻辑（scan_group_chats，与 assets/附_社交系统触发联动.md §12.5 一致）

```python
def scan_group_chats(state):         # M59
    for gc in asset_query("GROUP_CHAT", active=state):
        msgs = asset_roll("GROUP_CHAT", group=gc.id, source=GOSSIP_TOPICS)
        state.player.social.group_chat.extend(msgs)               # 群消息
        if any(m.trigger_event for m in msgs):
            state.events.pending.append(msgs.trigger_event)       # 群聊触发事件
        # 冷场 → 沉淀 ghost 素材（M65 结算）
```

> 联动对照（源文 §12.6 矩阵编号为源切片残留，实际对象）：群聊触发点 → 事件:M22；话题池 → 资产键 GOSSIP_TOPICS（素材系统语义即资产池）；消息文本表面反应 → 写作 DNA 经 M80；冷场遗憾 → M65（R1 事件桥）。

## 5. 事件契约

```yaml

subscribe:
  quest_state:          # M06 任务进展 → 群聊话题随任务语境刷新
  npc_action:           # 情感:M22 冲动行为 → NPC 群内发言语境生成
  relationship_change:  # M40 好感度档位变化 → 群内互动频率/内容重算
```

## 6. 违例与边界

- 群消息为群成员表层表达，不得泄漏系统真知（M23 认知边界）。
- 恋爱对象私聊/专属内容归 M41 恋爱系统管，本模块只做公开群层（M41 专属动态/私聊群在 M41 侧扩展）。
- 三冲动不驱动关系推进类群内容（v0.7.12 红线）；玩家是否参与群聊由玩家决定。
- 冷场不自动补剧情，只沉淀 ghost 素材供 M65 在窗口期显形。
