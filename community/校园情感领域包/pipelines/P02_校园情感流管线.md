# 管线 P02 · 校园情感流管线
> 社区版“校园预设”使用的管线。以关系深度与恋爱进阶为叙事主轴：角色状态层侧重人格/认知/恐惧画像，事件生产层优先产出日常互动与隐藏事件，行为决策层由三冲动与情敌/情书系统主导。
> 实例声明：本管线是通用骨架 **P00**（03_管线库/P00_通用文档生成管线.md）在**叙事领域·校园情感流**的装配——九层位名与模块挂载为领域特化。
```yaml
Pipeline:
  id: P02
  name: 校园情感流管线
  structure:
    type: linear
    flow:
      - from: P00
        to: P10
      - from: P10
        to: P20
      - from: P20
        to: P30
      - from: P30
        to: P40
      - from: P40
        to: P50
      - from: P50
        to: P60
      - from: P60
        to: P70
      - from: P70
        to: P80
      - from: P80
        to: P00
        condition: 主循环回卷（M50 调度下一回合）
  layers:
    - id: P00
      name: 数据基座
      description: 存档装载；校园存档含 relationships/active_quests/ghost_data
      optional: false
      default_modules: [M00]
      allowed_modules: [M00, M20]
    - id: P10
      name: 世界推进
      description: 校园作息时间（节/课间/放学）+ 天气 + 季节事件
      optional: false
      default_modules: [通用:M10, M08]
      allowed_modules: [通用:M10, M08]
    - id: P20
      name: 角色状态
      description: 人格画像（大五→三冲动基线）、认知边界裁剪、遗憾与隐藏事件装载
      optional: false
      default_modules: [M23, 情感:M22]
      allowed_modules: [M23, 情感:M22, M01, M02, M19]
    - id: P30
      name: 事件生产
      description: 日常事件流：闲聊话题、论坛热帖、家庭/习惯细节、隐藏事件状态机触发
      optional: false
      default_modules: [事件:M22, M06, M13, M12]
      allowed_modules: [事件:M22, M06, M13, M12, M18]
    - id: P40
      name: 关系决策
      description: 三冲动裁决 NPC 反应；关系深度升级、恋爱进阶、情敌竞争、匿名情书推进
      optional: false
      default_modules: [情感:M22, M40, M41, M43, M55]
      allowed_modules: [情感:M22, M40, M41, M43, M55]
    - id: P50
      name: 交互执行
      description: 对话与社交行为执行（互动深度结算：频率→认知、质量→下限线）
      optional: false
      default_modules: [M12, M13]
      allowed_modules: [M12, M13, M04, M11, M17]
    - id: P60
      name: 长期演变
      description: 关系网演化、遗憾沉淀与幽灵事件冷却、人格演变规则结算
      optional: true
      default_modules: [M40, M65]
      allowed_modules: [M40, M65, M07, M09, M14, M15, M16]
    - id: P70
      name: 叙事素材
      description: 世界知识库提供校园人物/地点常识；写作 DNA 供输出层调用
      optional: true
      default_modules: [M20, M24]
      allowed_modules: [M20, M24]
    - id: P80
      name: 输出呈现
      description: 现实/GAL 双模式渲染；现实模式隐藏数值与任务，GAL 模式显示关系标签
      optional: false
      default_modules: [M80]
      allowed_modules: [M80]
  dependencies:
    - from: P20
      to: P30
      reason: 人格与恐惧画像决定可触发事件
    - from: P30
      to: P40
      reason: 事件文本进入冲动扳机检测与关系裁决
    - from: P40
      to: P50
      reason: 关系决策落到对话/社交行为
    - from: P50
      to: P60
      reason: 互动结果写入关系网与遗憾沉淀
  tags: [人物驱动, 情绪流, 关系驱动]
```
## 运行规则
- 三冲动仅驱动 NPC；主角行为自由（情感:M22 主角豁免）。
- 每回合互动后检查 INTERACTION_DEPTH：频率提升认知、质量提升下限线、破坏可能击穿下限线触发关系事件。
- 遗憾显形只在事件:M22 允许的窗口内出现，且必须遵守写作 DNA 输出约束。
