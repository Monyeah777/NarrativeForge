# Narrative Forge · 文档生成工坊（规范驱动）

**Narrative Forge 是一台规范驱动的结构化文档生成器（元工具/文档工厂）**。它按协议校验结构，与文体无关：小说、技术文档、设定集都适用。叙事世界（P01/P02/P03）目前应用最成熟。

**生成路径**：自然语言意图 → 按协议模板填充（模块/管线/资产三正交装配）→ `bash verify.sh` 结构校验（十项门禁）→ 输出结构化文档/可运行世界。

**三个正交维度（均可增删改）**：
- 模块（04_模块库）：领域能力原语，按 01 §2 声明接口后登记即被调度。
- 管线（03_管线库）：数据流转骨架，含领域无关的 P00 通用骨架（装载→语境推进→实体状态→内容生产→决策→装配→一致性→素材→输出）；P01/P02/P03 是 P00 在叙事领域的实例装配。新领域复制 P00 派生新管线即可，引擎不改一行。
- 资产（05_资产库）：数据模板/素材，按键挂载供模块裁剪注入。

**快速开始**：将社区版预设（07_社区版预设.md）加载到 SillyTavern 即可运行校园（P02）/西幻（P03）模式，或按 01_核心协议 自定义装配。

**扩展新领域（三步）**：① 04_模块库按协议增领域模块 → ② 05_资产库增资产模板 → ③ 复制 P00 派生新管线并在 02_联动注册表登记，verify.sh 自动纳入 I5 调度。

**协议链**：01_核心协议 → 02_联动注册表 → 03_管线库 → 04_模块库 → 05_资产库 → 06_Agent执行协议 → 07_社区版预设。

**桌面工具**：`desktop/` 是这套协议的 GUI 实现（拖入 .md 模块 → 校验 → 勾选装配 → 输出文档）。Windows 构建入口：`desktop/packaging/build_windows.bat`，macOS / Linux 脚本在同目录。
