## 2. 运行期访问接口（与 02_联动注册表 对应）

本层文件为**静态数据源**；运行期统一经五类访问接口读取，禁止模块直读散文件：

| 接口 | 用途 | 对应文件 |
|------|------|----------|
| `asset_get(key, id)` | 按资产键 + 条目 ID 精确取单条 | 如 `asset_get("ATTR_TEMPLATES","T001")` |
| `asset_query(key, 条件)` | 按条件（tags / 类型 / 时段…）查询条目集 | 如 `asset_query("LOCATIONS", type=室内)` |
| `asset_match(key, 输入特征)` | 相似度匹配（人格推断 / 话题抽取） | 如 `asset_match("BIG5_INFER", behaviors)` |
| `asset_roll(key, 权重表)` | 按权重随机抽取（话题 / 事件 / 商品） | 如 `asset_roll("GOSSIP_TOPICS")` |
| `asset_register(key, 新条目)` | 用户自定义条目注册（进 用户自定义包） | 见 README §4 |

> 接口详细约定见源框架「3.2 五类统一访问接口」与 02_联动注册表.md。

## 4. 扩增协议（新增资产 → 用户自定义包）

1. **唯一 ID**：沿用资产键前缀 + 序号，后缀区 900+（官方 001-899，自定义 900+），如 `T901`。
2. **schema 必填**：新增条目须满足对应资产键的 `required_fields` 与 `field_types`（见 校园包/README §3 与源文件第 3 章 3.1.1）。
3. **注册登记**：经 `asset_register` 登记后写入 05_资产库/用户自定义/，禁止改写官方包。
4. **三原则**：不覆盖官方条目 / 不污染官方命名空间 / 可追溯（注明创建时间与用途）。
