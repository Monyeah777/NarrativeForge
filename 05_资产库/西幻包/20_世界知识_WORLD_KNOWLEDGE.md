#### 20.1.4 物理与魔法法则（physics + magic）

（一）物理法则

| 法则 | 规则 |
|------|------|
| 重力 | 正常，坠落会受伤甚至死亡 |
| 浮力 | 木头可浮于水面，金属会沉没 |
| 火 | 可燃烧木材/布料/干草，水灭火，油助燃 |
| 水 | 可解渴，可淹死生物 |
| 天气 | 下雨淋湿、下雪积雪、暴风雪冻伤 |
| 时间 | 白天明亮，夜晚黑暗，需要光源 |

（二）魔法法则

- **元素**：火、水、风、土、雷、光、暗（7系）。
- **魔力来源**：生物自身或环境。
- **施法方式**：需吟唱、手势或法杖，消耗魔力。
- **魔法反噬**：可能导致受伤、失控或死亡。
- **元素交互**：火+水→蒸汽；火+风→扩散火势；火+土→熔岩；水+土→泥沼；水+雷→导电；雷+金属→导电。
- **禁忌魔法**：时间操控、即死魔法、灵魂抽取（禁用）。

#### 20.2.1 引擎加载与注入机制

- **无限可能解析引擎（InfinitePossibilityEngine）**：接受任意自然语言输入，解析意图、提取实体，基于世界规则和常识进行合理性判断，计算成功率，生成结果描述。
- **构造时注入外部数据**（`__init__`）：

| 数据套件 | 变量 | 用途 |
|---|---|---|
| intent_patterns | 意图识别模式 | 从自然语言识别玩家意图 |
| entity_patterns | 实体提取模式 | 从文本提取NPC/物品等实体 |
| world_knowledge | 世界常识库 | 提供世界观、物理法则、种族、地理等常识 |
| action_rules | 行动规则库 | 每条含条件/基础难度/效果，判断行动可行性 |
| difficulty_tables | 难度表 | 环境、时间等因素的难度修正 |
| result_templates | 结果模板库 | 按意图与结果类型生成描述 |
| forbidden_actions | 禁止行动列表 | 破坏游戏平衡的行动关键词 |

- **预编译缓存**：`_compile_patterns()` 将意图与实体模式预编译为正则表达式（re.compile + IGNORECASE），提高解析效率。
- **主解析接口**：`parse_and_resolve(action_text, player_state, world_state)` 为对外主接口，构建 ParsingContext 后依次执行分词预处理、意图识别、实体提取、可行性判断、成功率计算、结果生成。

#### 20.2.2 合理性判断流程

- **前置禁止检查**：遍历 forbidden_actions，若玩家行动文本（小写）包含任一禁止关键词，直接判定不可行。
- **规则库查询**（`_query_feasibility_rules`）：
  - 遍历 action_rules 中每条规则，调用 `_rule_matches` 判断是否匹配当前上下文；
  - 规则 effect 为 forbid → 直接返回 False（禁止执行）；
  - 规则 effect 为 allow → 记录该规则至 context.rule_matches（后续用于成功率计算）；
  - 默认允许，可被后续规则覆盖。
- **规则条件匹配**（`_rule_matches`）四重检查：

| 条件类型 | 检查方式 |
|---|---|
| 意图匹配 | conditions.intent 与 context.intent 不一致则跳过 |
| 参数存在 | conditions.parameters 各项与 context.parameters 比对 |
| 属性要求 | player.attributes 中对应属性值 < 最低要求则失败 |
| 技能检查 | player.skills 中对应技能等级 < 最低要求则失败 |

- **世界常识约束**：可行性判断时从 world_knowledge 获取常识（如不能飞、不能空手碎大石等），作为规则引擎的兜底判断依据。

#### 20.2.3 外部数据接口与扩展

- **注册接口**：`register_infinite_engine(external_data)` 实例化引擎并注册到核心；在 `load_external_data()` 中调用。
- **调用链**：核心 resolve_custom / resolve_generic 将无法识别的行动交给 `EXTERNAL_DATA["parse_custom_action"](description, state, world)`，引擎返回的 state 已包含效果修改，可直接使用。
- **外部超级库需提供的数据**：intent_patterns、entity_patterns、world_knowledge（用于合理性判断）、action_rules、difficulty_tables、result_templates、forbidden_actions、intent_attribute_map（意图→主属性映射）、intent_skill_map（意图→相关技能列表）。
- **无限可能核心机制**：通过规则库动态判断而非硬编码，规则库可无限扩展，每添加一条新规则即可支持新类型的行动（@M21 数据接口联动）。
