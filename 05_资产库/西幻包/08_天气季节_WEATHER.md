- 事件触发流程：每日推进时按当前季节事件池掷骰（概率×条件判定）→ 命中则广播事件 → 相关区域/商店/任务按效果更新

### 5. 联动规则
- @M07旅行：天气/地形/光照/时段系数全部进入速度计算；北境冬季+暴风雪事件可叠加（速度×0.4×0.5）
- @M04战斗：元素伤害修正（火/冰/雷）按季节生效；雷暴事件额外+50%雷伤；夏季野外危险+1与地形系数交互
- @M05刷新：怪物刷新倍率（夏1.2/冬0.8）与资源刷新倍率（秋1.5/春1.2）作用于各刷新池；区域季节修正（北境冬0.5）二次覆盖
- @M06任务：季节事件可挂接任务链（「桃花汛」护送/修桥、「冬幕节」节日任务）；任务期限受季节切换约束
- @M01生存：饥饿/口渴/疲劳消耗倍率随季节变化；南境夏口渴2.0、北境冬饥饿1.3为极端场景
- 天气生成：进入新地点/每日推进时随机天气（倾向符合季节降水类型）；大雾/暴风雪等极端天气可被技能（M03）或道具（M05）抵消

### 6. 生成示例
```
场景：夏季第20天，玩家从海蓝港（南境）前往葡萄城（距离200米，平原/道路）
1. 季节判定：夏季——口渴消耗倍率1.5；南境区域修正：酷热/口渴2.0 → 实际口渴消耗 = 1.5 × 2.0 = 3.0倍
2. 天气晴朗1.0；地形道路1.1；光照白天1.0；时段10:00 → 1.0
3. 速度 = 基础50 × 1.0 × 1.1 × 1.0 × 1.0 = 55米/分钟 → 耗时200÷55 ≈ 3.6分钟
4. 抵达葡萄城：加载夏季描述「葡萄果实饱满，小镇弥漫果香」+ 环境帧
5. 季节事件检查：连续无雨7天 → 触发「干旱」概率0.15 → 若命中，水源价格+200%，附近农田减产30%
```
