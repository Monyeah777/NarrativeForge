### 2. 投资系统-店铺（investments.shops）
- 机制：投入资金获得店铺股份，每日结算日利润 = 投资额 × daily_profit_rate；风险判定（base_risk）失败则当日亏损
- 升级：满足 requirements 后花费 upgrade_costs 逐级升级，获得 upgrade_benefits 并提升日利润率
- 追加/赎回：投资额可在 min~max 区间内追加；退出返还本金（可能按风险折损）

### 4. 商店刷新与价格波动（shop_refresh_rules 复用+联动）
- 商店刷新基底：复用M05「商店刷新规则（按地区）」5城镇池结构（北境村/冰风城/海蓝港/铁炉堡/月隐城），每日/每周按 base_pool + extra_pools 概率抽取上架商品
- 价格波动公式：最终价格 = 商品基准价 × 市场事件倍率（M09）× 季节修正（M08）× 区域系数（M07 城镇1.0/道路1.1）
- 事件-库存联动：事件激活期间，受影响商品在对应区域商店刷新概率提升；短缺类事件（冬季短缺/矿难等）对应商品库存减半、价格按倍率上调
- 固定商品保护：fixed_items（北境村面包×5、冰风城冰钢×2/鲸油×3、铁炉堡秘银矿石×1@0.3、月隐城精灵工艺品×2）不受事件影响，保障基础供给

### 5. 经济联动规则
- @M05商品：37种商品基准价由M05 commodities 定义；本模块只做倍率调节，不重定义价格
- @M08季节：季节事件（丰收祭交易-10%、干旱水源+200%）与市场事件乘算叠加；南境热浪/北境暴风雪为季节与市场双重复合触发源
- @M06任务：市场事件可派生任务（「粮价飞涨」护送粮队、「瘟疫爆发」采集草药）；商路解锁依赖声望/阵营（faction_relations）
- @M07区域：市场事件按区域限定触发，跨区域旅行可脱离事件影响范围
- @M01财富：投资/商路收益计入财富；财富达标解锁高级投资（皇家商场需财富50000）
- 玩家干预：囤积/抛售、护送商队、清剿海盗（@M04战斗）可改变事件持续时间或提前解除

### 6. 生成示例
```
场景：秋季第15天，王冠城（中土），玩家财富8000、声望45
1. 市场事件判定：秋季+中土 → 掷骰命中「节日庆典」（概率0.04）→ 葡萄酒×1.3、矮人烈酒×1.3、精灵工艺品×1.2、宝石×1.2，持续5天
2. 商店价格计算：精灵工艺品基准价 ×1.2（节日庆典）×1.0（秋季节修正）×1.0（城镇）→ 商店刷新时精灵工艺品出现概率提升
3. 玩家投资「海蓝港贸易商行」5000金币：日利润 = 5000 × 0.02 = 100金币；风险判定（0.08）未命中 → 当日盈利100金币
4. 评估「龙之航线」：需声望50+财富50000（当前45/8000）→ 暂不可解锁；追加「南北商路」1000金币（声望10已满足，周期30天）
5. 玩家趁节日抛售库存精灵工艺品3件 → 盈利约60金币；若「商队被劫」触发则护送商队任务可提前解除风险
```
