#### 18.3 混沌引擎逻辑（FreedomManager）

> **数据源**：`/tmp/extract_test.txt` 行8390-8820，FreedomManager类完整实现（含init_chaos_state / resolve_chaos_action / 11个行为处理函数 / give_birth / change_lifestyle / check_physical_limits / generate_chaos_quest / commit_crime / register_chaos_rules / register_with_core）

**（一）引擎架构与数据加载**

- **FreedomManager**：自由度管理器，实现Elona-like混沌沙盒机制，与无限可能解析引擎协同处理各种离谱行为。
- **外部数据加载**（7套）：chaos_rules（混沌行为规则）、genetics_rules（遗传规则）、lifestyle_progressions（生活职业进度）、death_by_chaos（混沌致死）、pet_taming（驯服宠物）、mutation_table（突变特征列表）、wanted_crimes（通缉罪行表）。

**（二）行为判定与分发流程**

| 步骤 | 环节 | 说明 |
|------|------|------|
| 1 | 意图捕获 | 引擎解析玩家自由行动的intent与parameters |
| 2 | 意图识别 | `_identify_chaos_type` 使用 `chaos_rules.get("intent_to_chaos")` 映射表确定混沌类型 |
| 3 | 类型分发 | `resolve_chaos_action` 按类型分发到对应处理函数 |
| 4 | 兜底处理 | 未知类型走 `_generic_chaos` 通用混沌规则（基础成功率0.3） |
| 5 | 结果回写 | 处理结果写入玩家状态与世界状态，触发事件广播 |

- `init_chaos_state`：初始化混沌状态（混沌值、状态字段），在玩家状态创建时调用。
