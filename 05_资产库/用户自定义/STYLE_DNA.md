| 配置方式 | 位置 | 说明 |

## 3. 示例档：作者默认文学档（本源 = 校园情感包资产 5.11 WRITING_STYLE）
> 说明：以下为作者本人文风的档位示例（完整定义——违例/合规示例见 `community/校园情感领域包/assets/WRITING_STYLE.md`）。**这是示例不是协议**：任何用户/域包可整体替换为自有条目；未配置时风格门不生效。
| dna_id | 名称 | 规则（一句话） |
| --- | --- | --- |
| DNA1 | 情感永不直说 | 情绪装入物件与动作，读者从画面自行读出 |
| DNA2 | 物件即意象系统 | 核心物件跨代际反复出现，每次携带记忆重量 |
| DNA3 | 蒙太奇镜头感 | 极短段落/时间跳跃/指代模糊，段落如电影剪辑 |
| DNA4 | 白描与诗化交替 | 日常白描、高潮诗化，交替成呼吸感 |
| DNA5 | 感官以声触为主 | 声音与触觉优先，视觉为辅 |
| DNA6 | 双重真相写法 | 表层意象与深层真相共用同一画面 |
| DNA7 | 开放式结尾 | 结尾用超现实物象收束，答案留给读者 |
| DNA8 | 对话极简口语带潜台词 | 短句、口语、潜台词，没说出口的更重要 |
