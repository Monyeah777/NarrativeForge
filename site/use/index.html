二、agent（在本地跑通整个项目）

给能执行命令的 agent。完整命令序列与每步期望输出写在 /agent.txt；最小一段如下。

git clone https://github.com/Monyeah777/NinFenz && cd NinFenz
python scripts/nf.py doctor          # 期望末行：体检：16/16 通过
python tui/nf.py --selftest --json   # 期望：{"kind":"nf-tui-selftest","ok":true, ...}
bash verify.sh                       # 期望末行：结果统计: PASS=72  WARN=0  FAIL=0

python scripts/nf.py doctor末行 体检：16/16 通过，退出码 0

  • ⚠️ 官方唯一指定入口是 ninfenz.dev：没有付费版、没有客户端下载，也从不索取账号、手机号或支付信息。第三方站点（尤其带大量广告的资源 / 游戏 / 下载站）上的本项目内容与官方无关 —— 不要在那里输入任何信息或下载任何文件；真伪辨识见主页「官方唯一入口与防伪」。
  • 门禁管结构与可复现，不管文笔好坏——这条边界是设计的一部分。
  • 没有托管服务、没有付费版、没有遥测、不需要 API key：仓库就是全部，MIT。
  • 不编造编号：查不到就说「NF 库里没有」，留空并注明缺口。
  • npm 包已发布（包名 ninfenz v1.0.0，源码在 packaging/npm，发布带 provenance 来源证明）：npx -y ninfenz doctor（只读体检）与 npx -y ninfenz tui（全屏终端）免 clone 可用；若本机 npm 指向尚未同步的国内镜像，加 --registry https://registry.npmjs.org 或稍后再试。
