## 评估

- **并发写会让刚重冻的产物立刻变旧**：`verify.sh` / `scripts/nf.py` / `desktop/src/core/terminal.py`
  每改一次，绑定它们的审计即失效——40 条里绝大多数是这三者。收口必须安排在**写入停止之后**。
- **verify.sh 头部与自身正文不一致（只报不改：该文件是对方中央产物）**：头部「结构」注释写
  「[段 C] 代码层门禁（check12-**check32**…）」而同一文件的段标题 echo 写的是 **check12-check40**、
  真源 `quality_baseline.EXPECTED_CHECKS=40` 也是 40；且该注释的逐 check 枚举停在 check27
  （28-40 未列）。头部注释读起来是「当时的结构描述」，改动语义有歧义，故留给对方定稿——
  修法建议按仓库口径**改指针**（指向 `nf stats --check` 生成区与各 check 段标题），而不是再抄一遍范围。
- **对方 README 一处数字漂移（只报不改，因该文件由对方高频维护）**：`engine/rust/README.md` 覆盖表写
  「`nf conformance` 封缄内核 逐字节一致：**7,404 B**」，而 2026-10-03 实测真源报告为 **7,405 B**——
  **这个字节数本身是状态相关的**（审计契约的 `detail` 文本随审计新鲜度变化），钉死必然漂。同表其余
  三项实测仍准确：`receipts 55,727 B` ✓ / `stats 662 B` ✓ / `layers 189 B` ✓。修法二选一：
  同步为当前值，或按仓库「活文档不钉运行时计数」的口径改写为不钉字节数（后者不会复发）。
- **快线 oracle 为何只比 stdout、不碰 `--out`（实测决定 · 2026-10-03）**：① 语义上没必要——快线 `emit()`
  对两条路都是**原始字节**（`--out` 走 `fs::write`、stdout 走 `write_all`），实测 `stats` 的 `--out`
  落盘 **662 B 与 stdout 逐字节相同**；② 环境上会**造假红**——本机沙箱**只对 `nf-rs.exe` 写 `%TEMP%` 拒访问**
  （os error 5；实测 Python 的 e2e 与 Node 的 npm 物化写 `%TEMP%` 都正常——**不是整机限制，是这一进程**），
  而 `tempfile.TemporaryDirectory()` 默认落在 `%TEMP%`；要真写就得写进仓库内，判据便不再无副作用。
  故保持「只读 stdout」形态（现有用例里的 `--in` 是**读** `%TEMP%`，不受影响）。
  **附**：本条原本要写进 `test_rust_fastlane.py` 的判据头，但那次编辑被**并发保护挡下**
  （「file changed since it was read」——对方正在改同一文件），故改记在此处。
- **死代码判据的一个固有盲区（2026-10-04 实证，只报不改）**：`test_dead_code.zero_ref_defs` 按**名字**计数
  全仓出现次数（`counts[name]`），因此「同名函数活在另一个模块里」会遮蔽真正的死函数——本轮就是
  `driver.compile_plan`（零引用，但 `orchestration.compile_plan` 是活的）这样躲过判据的。
  **注意：朴素修法（把 `def <名>` 行从计数里剔除）修不了它**——因为 `orchestration.py` 内部**真的调用**
  自己的 `compile_plan`，名字计数仍然 >0；要真判出来需要**按模块限定 + 调用图**（或至少跟踪
  `from core.driver import X` / `driver.X` 这类限定引用），那与现有「简单文本启发式」的口径不是同一层。
  故本轮只删掉那一处死代码，并把这条边界记在此处；若将来要升级判据，先量同名方法（各类 `run`/`check`）

```python
import hashlib, re, sys
from pathlib import Path
ROOT = Path(".")
CHECK = "--check" in sys.argv
total = 0
for doc in sorted((ROOT / "results" / "audit").glob("*.md")):
    text = doc.read_text(encoding="utf-8")
    head, sep, body = text.partition("\n---\n")
    m = re.search(r"^subjects:\n((?:  - .*\n?)+)", head, re.M)
    if not m:
        continue
    changed, lines = [], []
    for line in m.group(1).splitlines():
        rel, _, old = line.strip().lstrip("- ").partition(":")
        p = ROOT / rel
        if not p.is_file():
            lines.append(line); continue
        new = hashlib.sha256(p.read_bytes()).hexdigest()
        if new != old:
            changed.append(rel)
        lines.append("  - %s:%s" % (rel, new))
    if changed and not CHECK:
        head = head[:m.start(1)] + "\n".join(lines) + "\n" + head[m.end(1):]
        doc.write_text(head + sep + body, encoding="utf-8", newline="\n")
    if changed:
        total += len(changed)
print("→ %s %d 件" % ("待重绑" if CHECK else "已重绑", total))
```
