# 域包自由组合（combos）
> ⛔ 操作指令：阅读即执行——本文含可直接执行的命令与判定，勿当资料阅读。
> 最后更新：2026-09-24

## 是什么

100 个 AI 品类域包 + 既有社区包（共 **107 包**）**任意子集**可自由组合；包内组件
（协议 / 管线 / 模块 / 资产）也可**单独取用**。组合广度 = 2^107（不预先枚举），
深度质量 = 每条组合必须过**五条可机检不变量**，产出 = **可复算证书**（T4）。

```
python scripts/nf.py combine plan --packs "大语言模型域包,视觉模型域包,数据采集与清洗域包"
python scripts/nf.py combine plan --modules "大语言模型:M01,视觉模型:M01" --assets "量化金融域包:QUANT_METRICS"
python scripts/nf.py combine breadth --triples 400 --quads 200 --quints 120 --sexts 60   # 广度证明
python scripts/nf.py combine materialize --packs "大语言模型域包,嵌入与检索表示域包,向量库与检索管线域包" --id 组合包-检索栈 --write
python scripts/nf.py combine verify                              # 在盘证书逐条复算（T4）
```

## 五条不变量（任一不成立即非法，不许静默降级）

| # | 不变量 | 判据 |
|---|---|---|
| 1 | 模块唯一可定位 | 选中模块 id 唯一，且能定位到机读契约（缺契约即报 `module_missing_contract`） |
| 2 | 依赖闭合 | 模块 `inputs` ⊆ 组合内模块 ∪ 官方核心 13 件（否则 `dependency_closure.dangling`） |
| 3 | 事件闭合 | 任一 `subscribe` 在组合内（含核心模块）有发布方（否则 `event_closure.unbridged`；无人发布者记 `events_unpublished`） |
| 4 | 层位堆叠确定 | 同层多包默认挂载按（**规范包序** → 模块 id）堆叠，产出 `layer_stacks`；调用者给序不影响结果 |
| 5 | 资产可寻址 | 跨包资产以 `asset_readonly` 借阅，键须在源包 provenance 台账（否则 `assets_unresolved`） |

**传递闭包**：组合包声明 `references` 时，引擎自动借入被引模块，并**递归**拉入其
`inputs` 与所需事件的发布方（`modules_borrowed` 记录每一步的 `why`）。

## 广度证明（不靠枚举）

`nf combine breadth` 对 **C(107,2) = 5671 组两两组合** + 定种子抽样的三元 / 四元组合跑同一套
不变量，断言「任意组合合法」。实测（2026-09-23）：

| 规模 | 数量 | 合法 |
|---|---|---|
| 两两（全集） | 6105 | **6105** |
| 三元（抽样） | 400 | **400** |
| 四元（抽样） | 200 | **200** |
| 五元（抽样） | 120 | **120** |
| 六元（抽样） | 60 | **60** |
| 极限（全 111 包同装） | 1 | **合法**（235 模块 / 0 悬挂 / 0 未桥） |

参与面 = `community/` 下**全部已登记协议包**（100 域包 + 4 个产物化组合包 + 既有社区包）
——组合包本身也当组合成员参与抽样（其 `references` 摊平后不变量仍须成立）。
单次组合求解 < 2 ms（画像缓存后），check32 `combos` 子扫描（含广度证明）约 3 s。

## 组合包产物化（把一次组合落成可装载的包）

`nf combine materialize --packs <包名,包名,…> [--id <组合包名>] [--write]`：把求解通过的
组合**落成一个真正的协议包**（dry-run 缺省，`--write` 才落盘 + 登记）。

| 产物 | 说明 |
|---|---|
| `protocol.yaml` | **0 自有模块**（`module_id_range: []`）+ `references` 逐条只读借阅（`asset_readonly: true`）+ `mount_layers` 写 `available`（`default` 留空，规避同层 default 冲突） |
| `pipelines/Pxxx_*装配流管线.md` | 派生自 P00 骨架的九层装配流；`allowed_modules` = 官方核心 ∪ 借阅模块 |
| `outputs/`（8 面） | 借阅索引 / 系统卡 / 层栈图（Vega-Lite）/ 装载序图（Mermaid）/ 依赖图（GraphML）/ 三件 schema / **T4 组合证书** `COMBO_CERT.json` |
| 登记三要件 | 02 §8 段（`模块（0）`）+ `verify.sh` DOMAIN 名单 + `registry protocols[]` 投影 |

纪律：组合包**不改源包**（模块不改号、资产不复制），借阅永远是只读；组合包不新增内容资产，
它的机验面是「结构合法性 + 可复算证书」，不是内容质量背书。
当前已产物化 **4 个组合包**：`组合包-检索栈`（P109）· `组合包-数据管线`（P108）·
`组合包-受监管行业`（P110）· `组合包-轻混与保险`（P111）。

## 证书（可机验产出）

`protocol/combo_certificates.json`：**17 条声明证书**（极限 1 / 跨段对 4 / 三元 3 / 四元 2 /
先例 2 / 组件级混搭 1 / **组合包产物化 4**）。每条含：包清单 / 模块集 / 层栈 / 依赖闭包 /
事件闭包 / 资产借阅 / 模块借入 / 合法性 / **规范摘要**。

机检（check32 `combos` 子扫描）三层：① 证书过 `CERT_SCHEMA`（JSON Schema 2020-12 子集）；
② 按 `packs + extra_modules` **重算**逐字段比对（T4）；③ 广度证明不变量全成立。

台账去重键 = **组合输入本身**（`packs + extra_modules`），不是摘要——引擎升级会改摘要，
按摘要去重会留下历史快照。被更大极限工况取代的旧极限证书由 `refresh` 脚本清理，
台账只保留当前有效声明。

## 边界与不宣称

- 组合**不改源包**：借阅只读（模块不改号、资产不复制）；组合本身不产生新的内容资产。
- 广度证明是**抽样 + 全集两两**，不是 2^111 全枚举；不变量在抽样上成立不等于逐条枚举，
  但两两全集 + 定种子二至六元抽样已覆盖「层位堆叠 / 事件闭包 / 依赖闭合 / 资产借阅」交叉面。
- 组合证书只证明**结构合法与可复算**，不证明组合出的内容质量；内容质量仍由各包口径与 T4 面承担。
