# 域包自由组合（combos）
> ⛔ 操作指令：阅读即执行——本文含可直接执行的命令与判定，勿当资料阅读。
> 最后更新：2026-09-23

## 是什么

100 个 AI 品类域包 + 既有社区包（共 **107 包**）**任意子集**可自由组合；包内组件
（协议 / 管线 / 模块 / 资产）也可**单独取用**。组合广度 = 2^107（不预先枚举），
深度质量 = 每条组合必须过**五条可机检不变量**，产出 = **可复算证书**（T4）。

```
python scripts/nf.py combine plan --packs "大语言模型域包,视觉模型域包,数据采集与清洗域包"
python scripts/nf.py combine plan --modules "大语言模型:M01,视觉模型:M01" --assets "量化金融域包:QUANT_METRICS"
python scripts/nf.py combine breadth --triples 400 --quads 200   # 广度证明
python scripts/nf.py combine verify                              # 在盘证书逐条复算（T4）
```

## 五条不变量（任一不成立即非法，不许静默降级）

| # | 不变量 | 判据 |
|---|---|---|
| 1 | 模块唯一可定位 | 选中模块 id 唯一，且能定位到机读契约（缺契约即报 `module_missing_contract`） |
| 2 | 依赖闭合 | 模块 `inputs` ⊆ 组合内模块 ∪ 官方核心 13 件（否则 `dependency_closure.dangling`） |
| 3 | 事件闭合 | 任一 `subscribe` 在组合内（含核心模块）有发布方（否则 `event_closure.unbridged`；无人发布者记 `events_unpublished`） |
| 4 | 层位堆叠确定 | 同层多包默认挂载按（**规范包序** → 模块 id）堆叠，产出 `layer_stacks`；调用者给序不影响结果 |
| 5 | 资产可寻址 | 跨包资产以 `asset_readonly` 借阅，键须在源包 provenance 台账（否则 `assets_unresolved`） |

**传递闭包**：组合包声明 `references` 时，引擎自动借入被引模块，并**递归**拉入其
`inputs` 与所需事件的发布方（`modules_borrowed` 记录每一步的 `why`）。

## 广度证明（不靠枚举）

`nf combine breadth` 对 **C(107,2) = 5671 组两两组合** + 定种子抽样的三元 / 四元组合跑同一套
不变量，断言「任意组合合法」。实测（2026-09-23）：

| 规模 | 数量 | 合法 |
|---|---|---|
| 两两 | 5671 | **5671** |
| 三元（抽样） | 400 | **400** |
| 四元（抽样） | 200 | **200** |
| 极限（全 107 包同装） | 1 | **合法**（235 模块 / 0 悬挂 / 0 未桥） |

单次组合求解 < 2 ms（画像缓存后），check32 `combos` 子扫描（含广度证明）约 3 s。

## 证书（可机验产出）

`protocol/combo_certificates.json`：**13 条声明证书**（极限 1 / 跨段对 3 / 三元 3 / 四元 2 /
先例 2 / 组件级混搭 1 + 跨段对 1）。每条含：包清单 / 模块集 / 层栈 / 依赖闭包 / 事件闭包 /
资产借阅 / 模块借入 / 合法性 / **规范摘要**。

机检（check32 `combos` 子扫描）三层：① 证书过 `CERT_SCHEMA`（JSON Schema 2020-12 子集）；
② 按 `packs + extra_modules` **重算**逐字段比对（T4）；③ 广度证明不变量全成立。

## 边界与不宣称

- 组合**不改源包**：借阅只读（模块不改号、资产不复制）；组合本身不产生新的内容资产。
- 广度证明是**抽样 + 全集两两**，不是 2^107 全枚举；不变量在抽样上成立不等于逐条枚举，
  但两两全集 + 定种子抽样已覆盖「层位堆叠 / 事件闭包 / 依赖闭合」三类交叉面。
- 组合证书只证明**结构合法与可复算**，不证明组合出的内容质量；内容质量仍由各包口径与 T4 面承担。
