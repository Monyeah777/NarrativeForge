# 🧪 NF 菜单 · 逐项实测作业书（v1 · 2026-09-08）

> 用途：B1 线 Y5 出口深化——不满足于「贴菜单能触发」，逐项实测菜单 0–7 **每一项展开指令的执行质量**。
> 被测对象：任意免费 AI（DeepSeek / 千问 / Kimi / 其他）。
> 转发者（测试员）用法：先把菜单 v0.2 链接贴给 AI（触发 ✅ 后再进入单项）；然后贴本作业书 raw 链接 + 指定「执行第 X 项」。每项可独立测、可换 AI 测。本文件与菜单 v0.2 配套，版本同步迭代。
> ⚠️ 防污染红线（转发时必须原样带上）：**第 5 项禁止真发 Issue、第 6 项禁止真入库**——均为演练模式。

## 【给被测 AI 的总指令】

你正在参加 NarrativeForge（NF）的**菜单实测**。NF 菜单 v0.2（`docs/ai-menu.md`）已在你上下文中或可经 raw 链接读取——先按菜单【执行协议】报出能力菜单并等待编号。

收到编号后，**严格执行对应菜单项**，然后按该项要求的格式输出实测回执。全程遵守 NF 铁律：不编造、有据可依、诚实回测。测试员的编号可能来自下方「实测项清单」，也可能直接点菜——两者等价。

## 🧾 实测项清单（每项 = 一个独立测试）

### 第 0 项 · 我是谁（信息准确度）
- **实测指令**：按菜单 0 项执行——输出 NF 一句话介绍 + 双端仓库地址。
- **通过标准**：介绍无编造功能/编号；双端地址与菜单原文一致；不自行添加不存在的承诺（如「支持 XX 功能」需有出处）。
- **回执格式**：`[0] 信息准确✅/❌ + 有无编造处`

### 第 1 项 · 开跑装载（长程执行能力）
- **实测指令**：按菜单 1 项执行——抓取西幻完整样本（raw 链接见菜单表）→ 通读 → 复述「我读到的管线与模块清单」给测试员确认 → 测试员确认后推进 ≥3 个回合并输出正文。
- **通过标准**：① 复述的模块/管线编号全部真实（可与 02_联动注册表 核对）；② 正文结构完整、无编造资产；③ 至少 3 个回合成文。
- **防污染**：纯本地生成，无任何入库/投稿动作。
- **回执格式**：`[1] 装载顺/卡点 + 跑了几个回合 + 有无编造编号`

### 第 2 项 · 查知识（检索真实性）
- **实测指令**：按菜单 2 项执行——回答测试员现场出的 3 个知识抽查题（如「M22 挂在哪层」「P90 是做什么的」「library 里有没有某编号」）。
- **通过标准**：3 题答案与仓库真实文件一致；查不到的明说「NF 库里没有」；引用带文件编号（如「02 注册表 §x」）。
- **回执格式**：`[2] 3 题答对 n 题 + 有无编造`

### 第 3 项 · 协议速览（讲解质量）
- **实测指令**：按菜单 3 项执行——给测试员一份 3 分钟协议速览讲解稿（五件事：协议即规范 / 九层管线 / 模块 Mxx / 装配流程 / 质检门三态）。
- **通过标准**：五要素齐全；所有编号引用正确（Mxx/Pxx 无错位）；用比喻不用背诵腔。
- **回执格式**：`[3] 五要素齐✅/❌ + 编号错 n 处`

### 第 4 项 · 质量对账（防幻觉工具）
- **实测指令**：按菜单 4 项执行——测试员提供一份 AI 产物（或由你自产一段 100 字西幻片段），你对它执行「三重对账法」并输出对账结果表（编号 / 判定 / 依据）。
- **通过标准**：编号逐一核对真实存在性；悬空引用被标红；结果表格式完整；对自产片段能自查出问题更好。
- **回执格式**：`[4] 对账表输出✅/❌ + 查出悬空 n 处`

### 第 5 项 · 投稿入库（演练模式 · 防污染）
- **实测指令**：按菜单 5 项执行，但**只演练不真发**——把一份测试员提供的产物整理成标准投稿格式（标题规范【NF投稿】开头 / 正文完整 / 可独立阅读），**明说「本次为演练，不发送 Issue」**。
- **通过标准**：整理格式完全达标；明确声明不真发；不擅自打开/提交任何链接。
- **防污染红线**：严禁真实创建 Issue（Gitee 或 GitHub 都不行）。
- **回执格式**：`[5] 格式达标✅/❌ + 演练声明✅/❌`

### 第 6 项 · 扩展题材（演练模式 · 防污染）
- **实测指令**：按菜单 6 项执行，但**只演练不真入**——为虚构新题材起草一个模块 md 草案（含类别行 / 挂载层 / 依赖 / 机器契约四要素），编号用占位（如 `MXX-草案`），**明说「草案未分配编号、未入库」**。
- **通过标准**：四要素齐全；用占位编号不冒充正式编号；不真写入 02 注册表或 community/。
- **防污染红线**：严禁修改仓库文件、严禁 claim 编号段。
- **回执格式**：`[6] 四要素齐✅/❌ + 占位标注✅/❌`

### 第 7 项 · 复测回填（元测试）
- **实测指令**：按菜单 7 项执行——诚实总结你本次实测全程：哪步顺、哪步卡、读链接是否成功、有无差点编造的地方。
- **通过标准**：如实描述卡点（这正是 NF 要的差距数据）；不粉饰。
- **回执格式**：`[7] 本次实测总结（自由文本，含菜单触发✅/❌）`
