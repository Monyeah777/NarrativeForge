# 41 波C C9 · 回合装载指针 v0（分层加载试点 · 格式定义 + P03 回合样例）

> 定位：40 总纲波 C–N 架构试点挂账项收编（41 §八 C9）。协议层固定区可预算化 → 档位装配层产出「回合装载指针」——每回合微型装配单：**常驻** = 协议要点 + 当前管线路径 + 结构门铁律；**热区** = 当前层模块契约 + 场景资产；**冷区不加载**、经键引用现取。
> 纪律：分级**不进协议正文**（01/02 契约字段零改动）；verify 不破（纯文档 + 样例）。

## 一、指针格式定义（v0）

每回合指针为单文件、人读优先（与仓库 md 哲学一致），字段如下：

```text
回合指针 v0
- 回合：<step 编号>
- 管线路径：<03 或 community/<包>/pipelines/<Pxx>.md>
- [常驻] 协议要点：01 §<章节>（<一句要点>）/ 02 §<章节>（<一句要点>）/ 06 §<章节>
- [常驻] 结构门铁律：<该管线默认装配要满足的门禁，如 check15/16/24 要点>
- [热区] 当前层模块契约：<Pxx 层 default 模块 full_id 清单>
- [热区] 场景资产：<资产键清单（随包 assets/，冷区经键引用）>
- [冷区] 不加载、经键引用现取：<Mxx / 资产键 清单>
```

预算纪律：常驻 + 热区为本回合**必须装载**；冷区仅记键、不内嵌正文——把每回合 token 面
压到「协议骨架 + 本层契约 + 本回合场景」，按需向 01/02/04/community assets 现取。

## 二、P03 西幻生存流回合样例（第 5 回合「洞窟遭遇战」）

> 样例管线：`community/西幻生存领域包/pipelines/P03_西幻生存流管线.md`（default 24 = 核心 11 + 题材 13，M03/M23 为 P20 allowed 备选）。以下为示例回合指针，可复现（随包文档在场即可逐项核对键）。

```text
回合指针 v0 · P03 第 5 回合
- 回合：5（洞窟遭遇战）
- 管线路径：community/西幻生存领域包/pipelines/P03_西幻生存流管线.md
- [常驻] 协议要点：01 §2 模块协议（模块经 inputs/outputs/events 通信，不直调）；02 §6 执行顺序（真相源）；06 §3 回合推进骨架
- [常驻] 结构门铁律：装配默认槽无冲突（check15）；machine_contract 契约闭合（check26）；模块状态 active（check24）
- [热区] 当前层模块契约：P30 事件生产 default（生存:M10 / 西幻:M22 等，见包 README 装配清单）
- [热区] 场景资产：assets/ 遭遇类资产键（随包 assets/README 溯源索引）
- [冷区] 不加载、经键引用现取：M20 世界知识库（实体/地点条目）、M23 认知边界（非本层按引用现取）
```

样例自检：常驻/热区/冷区三区齐备；未内嵌任何协议正文新增字段；未改动 01/02/03/04/community 既有文件。

## 三、v0 试点结论

- **可预算化成立**：指针把单回合装载压缩为「协议骨架引用 + 本层模块契约 + 场景资产键」三层，冷区引用现取不预载。
- **不进协议正文**：01/02 零改动；指针是档位装配层（运行时/Agent 侧）产物，非协议字段。
- **验收**：样例可复现（随 P03 包文档在册即可核对）；verify 不破（纯文档，PASS 39 复核）。
