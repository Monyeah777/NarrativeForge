# 45 · 执行遥测规范（真实转录/E3 补测底座）

> ⛔ 操作指令：执行留痕格式与采集器口径（阅读即执行）。
> 最后更新：2026-09-09

## 目的

动态可执行保真缺「真实 AI 执行转录」——封闭期不引外部实测（E3 作者触发）。在等真实转录前，先立**执行遥测格式与落盘面**：`nf assemble --trace <file.json>` 把每次计划/澄清/验收运行留痕，将来 E3 真实转录按同一结构回填即可做对比。

## 格式（nf assemble --trace）

```json
{
  "tool": "nf assemble",
  "phase": "plan | clarify | check",
  "requirement": "<用户一句话>",
  "status": "preset | custom",
  "matched": true,
  "package": "西幻生存领域包",
  "pipeline": "P03",
  "allowed_modules": 44,
  "ok": true,
  "issues": [],
  "stats": {"segments": 8}
}
```

## 采集纪律

- phase=plan/clarify：需求→计划/澄清留痕；phase=check：成品验收留痕（issues/stats）。
- 时间戳不写入（确定性优先，与 golden 同纪律）；需时序时由采集方外套 UTC 字段。
- 真实转录（AI 执行回合/输出文本）到位后：同一结构增 phase=execution 与 transcript 字段，按 E3 一次性补测回填。
