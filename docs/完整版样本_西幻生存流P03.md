## 1. 世界速览

- **定位**：西幻大陆，**生存驱动**的冒险流——职业成长 → 事件/混沌 → 战斗/生产 → 经济与势力演变，死亡可重生、长期可继承。
- **玩法主轴**：生存驱动（六维 vitals 逐分钟消耗，须在野外求生与城镇经营间平衡）；长期线 = 职业等级 / 阵营声望 / 帮派地盘 / 建筑据点 / 遗传后代。
- **输出风格**：结算可读化 + 状态面板 + 死亡/重生叙事（写作 DNA 八条质检门由 M80 把关）；现实模式隐藏数值面板。
- **时间制**：分钟制（10 分钟刻）；生存消耗逐刻结算（M01 统一）。
- **死亡规则**：health=0 → 生存:M10 死亡判定 → 重生（死亡祝福/遗物继承），**不结束游戏**。
- **存档键**：attributes+vitals / economy / relations（阵营声望）/ death_blessings / 世界档案（区域/帮派/建筑）。
