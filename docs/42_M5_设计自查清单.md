# 42 M5.5 · 设计原则自查清单（SOLID/YAGNI/DRY NF 化）

> 适用对象：04 模块 / 协议条款 / 新能力的开发与收口自检（每件产出提交前过一遍）。

| 原则 | NF 化表述 | 自检问题 |
|---|---|---|
| 单一职责 | 一件一契约 | 该模块/条款是否只做一件事？是否混了两种职责？ |
| 开闭原则 | 扩展走档位化 | 加能力是否走新增资产/模块/协议条款，而非直改既有契约行为？ |
| 无重复（DRY） | 复用资产化 | 同一知识是否复制到了两处？应引资产键 / 单一真相源引用？ |
| 单一真相源（I5） | 登记注册双源一致 | 文档声明与 registry/机读投影是否一致？谁是真源？ |
| 最小必要（YAGNI） | 按需装配 | 没消费方的新设施是否已拒建？标准/方案是否先过仓库实证？ |
| 组合优于继承（档位） | 装配/资产组合 | 是否用模块/资产组合表达，而非造新引擎分支？ |

verify 抽检：协议层新增条款须带编号 + 机读投影（check13/25/26/27 覆盖层）；纯逻辑件过 check12 + check27 R4（错误消息修复指引）。
