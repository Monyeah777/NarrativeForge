## 三、建议（低密度处理）

1. 用户自定义槽位不设填充目标——出现真实消费方（模块要挂自定义键）再补厚；
2. techdoc 类 0-资产包如需「术语表/修订模板」资产，随 42 M2/M4 判级器与内容边界产出再定（不无引用造资产）；
3. 低引用键淘汰动作仅在「引用计数 = 0 且无计划消费方」时触发（当前无此键）。

## 四、结论

资产层当前**语义厚度足、无孤儿、无低密度应淘汰键**；低密度面均属「按需等待消费方」，非缺陷。
